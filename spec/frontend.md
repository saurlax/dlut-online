# 前端与像素世界

## 当前入口

Next.js 以 SSG 模式生成产品入口和静态 404 页面。页面语言为简体中文，保留字体默认字间距，不引入外部字体请求。初始化页面只介绍产品，不展示尚不可用的游戏按钮、在线人数或伪造校园画面。

## 游戏实现目标

Phaser 负责俯视二维像素世界，使用 WebGL 绘制；React 管理页面、表单、菜单和游戏实例挂载，不驱动逐帧模拟。游戏模块仅在浏览器按需加载，离开游戏时销毁实例和监听器。

优先建设有参考资料支持的小范围校园。采用统一像素网格、角色比例和遮挡规则，地面碰撞与装饰分离。昼夜、局部光晕、天气粒子和着色器服务于校园氛围；实时遮挡阴影在明确需求与性能验证后引入。

移动、朝向、失焦停止、暂停与恢复需同时考虑键盘和触屏。客户端预测与插值不改变后端权威状态；断线时停止发送移动，并明确显示连接状态。

## 边界

当前未添加 Phaser 依赖或场景；在实现第一段可操作游戏流程时再引入，避免初始化阶段维护空游戏和无用依赖。Next.js 不提供服务端 API 或实时游戏模拟。
