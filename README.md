**以大连理工大学为背景的浏览器像素多人在线游戏。**

DLUT Online 以俯视二维像素世界呈现校园，将真实的建筑、道路与公共空间融入多人在线体验。玩家通过浏览器走进校园，与其他玩家相遇，共同探索熟悉的场所。

## 校园世界

游戏以凌水、开发区和盘锦三个校区为内容范围，依据真实校园资料组织空间，保留各校区的布局与建筑特征。探索围绕校园中的道路、建筑和公共空间展开。

## 像素风格

统一的像素美术呈现校园建筑、自然景观与角色。昼夜、天气和环境光照共同塑造校园氛围，让同一处风景随时间与天气呈现不同的面貌。

## 多人探索

玩家在同一个校园世界中行走、相遇与交流。游戏以轻松的校园探索为核心，让空间中的共同经历成为在线体验的一部分。

## 浏览器体验

面向电脑和移动设备，通过浏览器访问，结合键盘与触屏操作提供校园探索体验。
