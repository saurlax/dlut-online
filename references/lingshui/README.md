# 凌水主校区建模依据

读取日期：2026-09-09。用户指定来源：[大连理工大学官方校园地图](http://map.dlut.edu.cn)。校区 ID 为 77291，原点沿用 `references/campuses.json` 的 (121.526958936262, 38.879216194937)。

## 布局数据

`bounds.json` 保存 [公开轮廓接口](http://map.dlut.edu.cn/openmap/mapi/bd/v1/bound) 的 438 条主校区及周边记录：所有顶点位于经度 (121.50,121.55)、纬度 (38.86,38.90)。全站原响应总数为 550。此筛选框不是官方校区红线。

`apps/client/tools/prepare_lingshui.py` 按明确名称排除周边文萃、文荟、新新园住宅、文静街与凌水路沿街住宅、中国大连高级经理学院及少量周边商铺，共 125 段；逐项列于 `excluded.json`。保留校园教学、生活、东山家属区及官方西校区范围，不复制其他校区数据。

模型数据保留 282 个 Feature ID、313 段轮廓：209 段建筑、48 段道路、22 段停车/广场、13 段运动场地、9 段校门地面轮廓、2 段水体、4 段规划用地，以及 6 段仅保留来源节点的桥梁/雕像记录。后两类没有被误生成现状建筑。道路直接使用官方占地多边形，不自行添加道路网。

同 ID 的多段道路不去重，节点采用 `Feature_<id>_<part>`，`source_index` 对应原始响应。坐标以 X 向东、Z 向南按纬度余弦转换为近似米制；未经坐标系校正和测绘验证。底座范围由轮廓外包框加 30 米得到，不代表校园红线；地面无实测高程。

现代实验楼（77419）官方轮廓有一处小自交。转换工具按线段的精确交点拆分为两个简单环，两块均保留；原始 `points` 不变，`render_polygons` 用于网格、地图和碰撞。因此渲染共 314 个有效环。其余轮廓均无此处理，不以凸包替代真实凹轮廓。

照片索引在 `photos/<id>.json`，完整请求 URL、读取日期及每张原图 `imageURL` 均保留。照片 URL 为 `http://map.dlut.edu.cn` 加 `imageURL`；本地序号从接口 `result` 的零起算位置取得。本仓库保留实际用于建模的 18 张照片，均仅作离线参考，不进入 Godot/Web 资源包。另五个已查询对象仅保留 JSON 索引供后续核对。

这些高度来自可见楼层和比例估计，不是实测。其余 202 个建筑轮廓没有逐栋外观精修，统一 18 米作为未测高度的轮廓表达，不代表真实楼高；没有添加通用窗格或移植其他建筑立面。自然材质纹理为程序生成，不是把照片贴进游戏。门廊只制作照片所见的外部柱和顶板，建筑背后的实体封闭，不包含入口通道。

## 当前限制

无室内模型、房间、家具、门厅、楼梯或可进入的建筑。照片中能看到的室内片段不足以建立有效平面。未建未核实的树木布局、桥梁结构、雕像造型、场地内部划线和地形坡度；校门只保留地图地面轮廓。西校区四栋标为“规划中”的宿舍仅作平面轮廓。

这是官方布局基础上的可行走初版主校区，七栋建筑具有局部照片参考立面，不是照片级复刻，也不是官方三维数据。后续实测或更完整照片应按同一 Feature ID 替换独立建筑。

## 再生成

在任意工作目录执行仓库中的 `apps/client/tools/export_web.sh`。工具从自身路径解析资料，只读取已归档数据；不依赖在线接口。单独再生成凌水时先运行 `python3 apps/client/tools/prepare_lingshui.py`，再运行 `godot --headless --path apps/client --script tools/build_lingshui.gd`。
