# 全景与卫星数据可用性调查

调查日期：2026-09-09。此次只核对数据源，未改变游戏模型或界面。

## 全景

- 用户提供入口：https://360.toowtech.com/dalian/DUT/
- 场景配置：https://imgs.toowtech.com/dalian/DUT/toowtech_kfq.xml
- 该入口分为伯川、令希、开发区、盘锦、马克思主义分馆。当前区域图书馆有 14 个点位：1 个航拍、1 个西门外景、12 个室内。
- 室内覆盖一楼大厅、二楼大厅、二楼阅览室及图书区、三楼阅览室及报纸/图书/期刊区。具体 ID 和跳转关系见 index.json。
- krpano 多分辨率立方体图片：室内配置最高每面 6400 像素，航拍最高每面 9216 像素，瓦片尺寸 512。最高层级由配置得出，未全量下载；已实际读取和查看 3 张 1536×1536 VR 面图样本。
- 样本源 URL 分别为 https://imgs.toowtech.com/dalian/DUT/panos/DUT_KFQ02.tiles/vr/pano_f.jpg 、https://imgs.toowtech.com/dalian/DUT/panos/DUT_KFQ04.tiles/vr/pano_f.jpg 、https://imgs.toowtech.com/dalian/DUT/panos/DUT_KFQ00.tiles/vr/pano_d.jpg 。
- 大厅可见玻璃门、柱子、吊顶格栅灯、沙盘与石质地面；阅览室可见圆柱、门框、吊顶、桌椅及设备；航拍可见道路、铺装、花坛和树木分布。
- 每个点位 lat、lng、heading 字段均为空。热点 ath/atv 是看向目标的球面角度，不是实测世界坐标或距离。
- 场景配置未发现深度图、点云、网格、房间尺寸或标定相机位姿。全景图不能直接变成具备自由行走、视差与碰撞的三维场景。
- 本来源补充了真实室内视觉依据，取代“完全没有室内照片”的旧结论。但尚未建立房间尺寸与空间配准；不可据此补造盲区或完整平面图。

## 卫星与航拍

- 该全景站的 vtourskin.xml 明确 maps=false，没有启用卫星图层。西门鸟瞰为航拍全景，不是带地理配准的正射影像。
- 原官方地图 http://map.dlut.edu.cn/openmap/config/map-config.js 使用高德图层：http://webst04.is.autonavi.com/appmaptile?style=6&x={x}&y={y}&z={z} ，style=8 是标注叠加；配置层级 8–19。
- 抽样请求 z=18/x=219775/y=100106 成功返回 HTTP 200、256×256 JPEG。仅证明瓦片可读取，不证明此瓦片与现有场景已配准。
- 可用于核对屋顶、道路、绿地和平面关系；不能提供真实室内、立面或地形高程。
- 使用前应通过已知地物控制点核对地图坐标体系及偏移，不直接把经纬度当作已对齐的 WGS84 数据。配置最大缩放级别不等于影像实际分辨率。

## 对 DLUT Online 的使用方式

以官方轮廓定位建筑，以航拍/卫星核对室外布局，以全景核对可见内外细节。模型仍在 Godot 中制作，不新增全景网页或导览模式。先对图书馆西门—一楼大厅的可见范围建立对应关系，再确定能可靠重建的几何；未覆盖或无法确定的结构不做。

当前仅保存离线参考样本和索引，不打包到 Web。页面和配置中未找到允许在第三方游戏中复制发布影像的明确许可；如果将原图直接作为发布版贴图或全景背景，需要另外确认图像和地图服务的使用授权。
