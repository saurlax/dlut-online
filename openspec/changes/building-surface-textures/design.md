## Context

现有 `facades.json` 仅在 77390 和 77487 的已配准墙面声明 `small_tiles`。不扩充到未确认表面。原实现使用 256 像素程序色块与世界三平面投影。

## Goals / Non-Goals

改善两处已有墙面的近景质感与斜墙砖缝比例。不修改几何、碰撞、门窗布局或新建室内，不将参考照片作为运行时贴图。

## Decisions

使用一张共享中性色生成贴图，再乘已有颜色；生成原图 1254×1254，导入最大 1024，开启 S3TC/ETC2 压缩和 mipmap。保留原有 0.4 米重复尺度（四列八行，非测量）。材质只设置颜色贴图与固定粗糙度，不虚称为扫描 PBR。

对 small_tiles 装饰墙片写入立面局部米制 UV，使用片段中心还原共同原点。旋转、合并静态网格后 UV 不变，窗口周围不会分别拉伸纹理。只变更装饰网格的 UV，不增加顶点或碰撞。

公开材质库核对 Poly Haven 与 ambientCG 的 CC0 许可；具体候选及未选原因记录在现有校区来源目录。生成贴图不混同为第三方 CC0 资产。

## Risks / Trade-offs

生成细节为视觉近似，对边不保证逐像素一致；需要实际重复铺贴检查。照片不能确认砖尺寸和微观粗糙度，保持标注。只适用于当前已核实区域，其他墙面仍保留原材质。
