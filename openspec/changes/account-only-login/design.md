## Context

多人模式玩家使用 PocketBase 真实账号。客户端登录方案改为 Godot 原生邮箱、密码表单，直接调用 PocketBase；网站保留账号登录、注册与邮箱验证。

## Goals / Non-Goals

**Goals:** 原生账号登录、已验证账号入场、取消与错误重试，不开启本机监听端口。
**Non-Goals:** 不实现 OIDC、移动端插件或导出、客户端注册表单，不保存密码，不改变校园模型。

## Decisions

- Godot 使用 LineEdit 输入邮箱和密码，密码隐藏，支持回车提交、重复提交保护、取消。提交立即清空密码框；密码不保存到文件或日志，token 在运行时保留于进程，并按 API 根地址隔离存入系统凭据库。
- HTTPRequest 直接调用 /api/collections/users/auth-with-password。PocketBase AuthRule 要求 verified=true 且 disabled=false；客户端检查返回账号，票据和游戏服再次验证身份，不存在游客降级。
- 删除桌面 TCPServer 回调、state/verifier/授权码及 Go /api/v1/auth/requests、approve、exchange；网站移除请求参数传递与返回游戏按钮。网站登录注册、验证邮件重发继续使用原生 PocketBase API。
- 客户端注册链接打开 https://dlut.online/register，只用于注册，不承担登录回调。新账号先在网站完成邮箱验证，再回到游戏输入邮箱密码。
- 多人模式只有收到游戏服 welcome 才进入世界。短暂网络故障返回主菜单，等待手动重连，认证失效清理会话并返回模式首页，切校区复用连接；取消后的迟到认证结果不得建立会话。
- DO_ENV 保留原有构建及运行时覆盖。production 客户端账号 API 使用 HTTPS；游戏传输按 enet:// 或 enets:// 选择，DTLS 校验失败不自动降级。Go 和游戏服 production 限制保留。
- 将来 OIDC 作为独立登录方式另行设计，移动平台按系统认证能力接入；当前不保留未使用的回调实现。

- macOS 使用钥匙串，Windows 使用凭据管理器。桥接仅依赖系统 security/PowerShell，通过管道传输 Token，不写明文文件或进程参数。凭据操作串行处理，退出先写无敏感信息的禁用标记，避免保存与删除竞态或删除失败导致自动重登。
- 首次点击多人模式时读取已有 Token 并调用 auth-refresh，成功后继续入场。启动首页和单人模式不执行凭据恢复；网络失败保留凭据，明确认证失败清除。
- 大地图提供退出登录；退出与游戏认证失效清理内存和系统凭据。凭据库不可用时允许本次手动登录，不回退到明文存储。

## Risks / Trade-offs

- 无效凭据、未验证或禁用账号不暴露额外账号信息，统一提示检查邮箱、密码及账号状态。
- 网络失败与超时恢复可操作表单，取消终止请求并丢弃迟到结果。
- SMTP 仍由部署配置，网站注册与验证邮件结果分开提示。

## Migration Plan

网站/API 与新版客户端共同发布。现有账号、游戏票据与协议 v5 不变，旧浏览器授权客户端需升级。移除未使用的回调接口及对应专用测试，保留真实 PocketBase 密码认证和账号安全检查。

## Startup Loading

main.tscn 提供单人模式和多人模式封面及只读校园背景。单人模式直接加载本地校园；多人模式点击后按账号状态直接连接或弹出登录表单，认证成功后继续加载和取票，welcome 后才允许行走。断线或退出回到模式首页，重连仍需点击多人模式。

## 主菜单与连接生命周期
首页显示单人模式与多人模式。点击多人模式后，有有效会话直接加载和连接，无会话弹出登录并尝试恢复；认证成功直接继续此次入场。加载和失败时显示必要状态。正常传送仍复用已有连接，不出现主菜单。

普通断线统一停止角色、释放鼠标、清理连接和传送状态并卸载校园，保留账号 token。连接代次拒绝迟到 HTTP 响应，加载代次拒绝旧传送结果；返回菜单后不会自动重试，玩家点击进入才取新票。明确认证失效或同账号被替换时仍删除凭据并返回模式首页。

本地转向即时更新；网络只在约 20 Hz 周期采样最新 yaw，方向键、停步、奔跑和跳跃边沿继续在对应物理步前发送并建立预测区间。游戏服保持每秒计数限制，上限 80，为默认 60 Hz 离散输入和控制消息留余量。协议数据格式和版本 5 不变，关闭码 4002 专用于版本，4005 为限流，4006 为无效消息；HTTP 错误体、地址配置与断线原因分别转换为原生菜单提示。

## 首屏视觉背景

当前首屏按 native-menu-theme 使用只读校园视觉模型轮播镜头。该背景不创建玩家或碰撞，也不发起游戏连接；只有选择单人模式或完成多人模式认证才加载可玩校园场景。背景的生命周期、取景与编辑器预览见 native-menu-theme。
