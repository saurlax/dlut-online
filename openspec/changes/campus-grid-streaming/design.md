## Context

动机见 proposal.md。现有 Web 以校区 PCK 下载，源码场景内静态模型完整挂载。

## Goals / Non-Goals

**Goals:** 网格渐进下载和有界细节实例；保留碰撞和照片依据。
**Non-Goals:** 新建建筑、室内、地理修正，桌面网络下载。

## Decisions

- Web 导出时转换场景，源场景不变。启动层保留基础地面、碰撞网格和建筑轮廓，细节按百米格输出。共享材质单独保存，随校区启动层下载。
- 建筑细节按整栋归属，索引覆盖全部相交格；道路和植被等非建筑网格按三角形裁切到格，插值位置、法线、UV、颜色。世界原点对齐，负坐标使用向下取整。
- 近处按格距离优先下载，加载半径 2 格，释放半径 3 格，避免来回走动抖动。每次一个下载/实例化，地图展示当前附近任务的 MB 计数与重试。
- 复用现有哈希校验加载器；网格包挂载后可复用，离开范围释放实例而非撤销 PCK 挂载。切换校园销毁调度器并取消请求。
- 碰撞骨架常驻，避免在弱网时增设空气墙或让玩家掉落；细节未到时仍可行走和看见真实建筑轮廓。

## Risks / Trade-offs

- 多次访问会积累挂载包及浏览器文件 → 如实区分实例释放和包挂载缓存，不承诺总内存恒定。
- 网格边缘增加三角形 → 验证裁切面积和属性，保持材质共享，不复制整片树冠。
- 细节首次出现仍有切换感 → 提前加载两格，保留远处建筑轮廓。
- 当前基础碰撞层仍随建筑规模增长 → 本次优先移出高体积装饰，后续按实测继续优化。

## Migration Plan

整体重新部署 Web 输出目录；旧校区包策略由本变更接替。源码编辑器及桌面使用完整场景，回滚通过旧版本完整导出。
