## Context
采用自建 Godot 人物系统和 CC0 素材基座，制作工具与运行系统分离。当前保持主项目的校园、网络和碰撞不变。
## Decisions
- 先完成可验证的动作及外观升级，保留男女样本和整套便装切换。
- 动画离线转换，不将素材供应方的程序引入客户端；来源及校验统一维护在人物清单和 CREDITS。
- 外观参数控制实例材质和形变，不修改共享资源；肤色是美术控制，不声称生理模拟。
## Risks / Trade-offs
动作重定向需验证脚部与肩肘；形变增加不代表所有组合已精修。Android 与 macOS 必须区分导出与真机验收。逐根发丝、布料模拟、全身体型、多人外观同步不属于本轮。

## Implementation
使用 Quaternius 经 Mesh2Motion CC0 仓库发布的 Blender 动作源，选择 Idle_A、Walk 和 Jog。离线将源骨骼全局旋转转换为目标局部旋转，对肢体绑定姿态、骨盆尺寸、头颈前倾做适配，24 fps 烘焙并显式保存全部轨道和骨架路径。不是动作捕捉，尚未加入脚底 IK，落脚仍需后续精修。

脸部控制由 4 项扩为 11 项，新增脸长、下巴长度/突出、鼻部长度/突出、嘴部高度和嘴部突出。对现有人体及面部配件传播同一组上游形变，范围仍为原始形变的 50%，不是高精度雕刻完成品。肤色深浅/冷暖通过实例 ShaderMaterial 调节，保留贴图纹理；红唇区域使用颜色启发式减少染色，不声称具有完整身体区域遮罩。皮肤使用温和的粗糙度/反光及 Forward+ 次表面散射，眼睛降低粗糙度；未新增扫描法线或毛孔贴图。

预览分为“捏脸”“肤色”两个原生页签；样本、整套服装、动作与观察按钮保持可见。重置恢复所有参数，样本切换保留参数。使用既有 build_samples.py、pack_samples.gd 和 export_preview.py 重建与导出，新 retarget_motion.py 仅离线运行。系统仍不连接账号与多人服务。
