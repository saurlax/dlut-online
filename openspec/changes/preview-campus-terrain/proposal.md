## Why

用户要求将已准备的高程数据替换到场景中查看效果，需要独立地形、物体落地及一致碰撞。

## What Changes

- 采用 OSM 匹配轮廓的经验平移，并明确预览误差。
- 从 DSM 生成过滤及局部地坪处理的近似地形，静态挂载两个校区。
- 调整建筑基面、道路及树木高度，移除原平板与示意山体，同步首页背景。
- 由共享场景生成客户端与服务端碰撞，更新来源声明。

## Capabilities

### New Capabilities

- `campus-terrain-preview`：两校区可行走地形预览。

### Modified Capabilities

无 API 或游戏协议变更。

## Impact

影响两校区模型、离线工具、共享碰撞和首页镜头。地图地形与建筑仍不具备实测精度，不新增建筑或室内。发布时客户端与游戏服须一同重建，数据库、API、环境变量、migration 和新增运行依赖：无。
