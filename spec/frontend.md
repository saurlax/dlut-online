# 前端与像素世界

## 当前入口

Next.js 以 SSG 模式生成产品入口、`/game/` 游戏页面和静态 404 页面。页面语言为简体中文，保留字体默认字间距，不引入外部字体请求。首页未登录显示“登录”，登录成功后显示“进入校园”，点击后准备角色再打开地图；游戏入口检查已准备的会话和令牌有效期，无有效会话时返回首页。首页与游戏之间使用原生链接做整页切换，不依赖静态服务器上的 RSC 分段预取重写。游戏页面根据地图数据和 Phaser 资源加载进度显示进度条，场景准备完成后显示游戏界面。

游戏时间使用服务器校准的北京时间，白天与夜晚根据实际时间变化。开发区校区天气来自 Open-Meteo，服务端每 15 分钟同步真实时间和天气并广播，客户端显示雨、雪或雾效果；同步失败时保留上次天气。管理员可临时使用指令调整时间或天气，下一次成功同步天气时恢复真实天气，每次同步均恢复真实时间。

未登录时首页登录弹窗提供游客进入。游客使用服务端签发的临时会话和“游客”加六位数字的名字，穿预设服装，可移动和聊天，不能修改装备或背包；不创建用户和角色记录。游客会话保存在当前标签页，12 小时后失效，服务器重启后需重新进入。

界面使用本地托管的缝合像素字体，选择 12px 简体中文比例版。所有可见文字，包括按钮、设置标题、错误和来源署名，使用同一原生字号，不使用合成粗体或斜体，保留默认字距。文字先在 12px 画布中以基线 10 栅格化，alpha 规整为 0 或 255，再随用户选择的界面倍率显示；DOM 保留原文供读屏与按钮名称读取。字库及 OFL 授权文件随静态资源发布，字体来源记录在 `CREDITS.md`。

## 显示像素网格

地图与界面使用独立的显示倍率，保留原生素材与最近邻采样，不要求二者的显示像素颗粒一致，不操作浏览器缩放。

地图与首页背景由 `game/pixel-grid.ts` 沿用原有显示规则：设浏览器 `devicePixelRatio` 为 d，一个原生像素占 `q = max(1, round(2 × d))` 个设备像素，对应 `q / d` 个 CSS 像素。DPR 不是显示器真实 PPI，不能仅凭 DPR 推导物理毫米。窗口和全屏尺寸变化时重算世界可见范围，DPR 变化时只重算世界画布倍率；Phaser 相机倍率为 1，画布最近邻放大，不叠加第二次相机缩放。

界面由 `game/interface-scale.ts` 独立计算：小、标准、大分别以 1、1.5、2 CSS 像素显示一个原生界面像素，默认标准（1.5×）。界面倍率不按 DPR 取整；逻辑界面视口为 `floor(window.innerWidth / scale)` × `floor(window.innerHeight / scale)`。设置中的“界面尺寸”即时切换，保存至本浏览器当前源的 `localStorage`（`do-interface-scale`），刷新及回到首页继续使用，其他同源标签页同步更新。

按钮、字体、图标、物品格、小地图、地图弹窗、账号与设置弹窗沿用所选界面倍率；实际校园瓦片、建筑、植被、人物、镜头和首页背景不受界面尺寸改变影响。首页 Logo 仍固定为 320×160 CSS 像素。界面按原生像素布局，弹窗与视口边界按界面逻辑坐标计算；窄屏的大尺寸界面允许物品栏横向滚动，数字键切换时将所选物品格滚入可见范围。按钮按压移动一个原生界面像素。所有界面禁用浏览器默认及自定义 outline，鼠标点击、Tab 和方向键聚焦不显示外部强调框；保留按钮按压、选中底色与物品格选中状态。

界面通过名称、层级和布局传达用途，不默认配套说明段落、副标题或提示卡。`description` 等说明组件仅用于用户操作和决策必需的信息；具体文案约定见 [开发约定](../DEVELOPMENT.md#界面与文案)。

按钮与链接复用 `components/game-button.tsx` 和同目录样式，使用大工蓝与书页白。按钮及窗口的外轮廓为一原生像素，按钮仅保留一像素高光、下沿阴影和按压位移，不叠加第二层内框、铆钉或厚色带。像素格对齐与线条重量分别核对，不能以同网格为由默认两像素描边与地图一像素细线具有相同颗粒感。文字按钮默认不配图标，文字居中且不保留图标占位；设置入口保留简化的线框齿轮，弹窗标题只显示文字。书籍与禾苗意象保留在固定 Logo 中。交互复杂度由按需引入的 Radix Primitives 承担，设置与关于使用 Dialog 并共享 `components/game-dialog.css`；视觉由项目样式控制，不引入整套通用视觉主题。

首页采用游戏标题画面：蓝色 DLUT Online 标志结合书籍与幼苗意象，背景为沿主楼中轴线正视主楼与毛泽东像的横向像素插画。标题放在上方天空，前景纵向放置“进入校园”和“关于”，保持地标可见，不添加介绍卡片或尚不可用的菜单入口。窄屏裁切同一横向插画，横屏低高度时按钮移到右下方。

“关于”集中展示 OpenStreetMap 数据署名及 ODbL 许可、缝合像素字体及 OFL、项目美术与实景和风格参考、Radix 及 MIT 许可，来源与 `CREDITS.md` 保持一致，提供可访问的来源和许可链接。弹窗沿用像素字体及界面显示网格，长内容可滚动，滚动位置对齐原生像素，标题栏右上角提供 X 关闭按钮；支持 Escape、点击遮罩关闭和焦点恢复。界面按逻辑视口收紧窄屏和低高度布局，长版权文字在原生画布内换行，保持相同字形网格与原始可访问名称。不在地图画面叠加版权署名。

标题插画使用 imagegen 生成，再通过 `tools/prepare_title_assets.py` 最近邻采样并规整调色板。正式背景为 512×288、最多 64 色，透明标志为 320×160、最多 40 种可见颜色且 alpha 仅取 0 或 255。标志直接作为固定 320×160 CSS 像素的图片居中显示，不放进背景画布、不在窗口变化时重新采样或放大。背景单独以最近邻采样到世界网格的原生画布，再按世界倍率显示；不加载生成时的大图或实景照片。来源、提示词与像素处理约定记录在 `references/branding/title-screen.json`。首页插画独立于地理网格，不作为地图几何依据。

所有弹窗（账号、角色创建、背包、地图、设置、关于）统一使用固定 286 原生像素宽度；窄屏时只按视口可用宽度收紧，取偶数原生像素保证居中对齐，不根据标题、地标名称或正文长度改变宽度。标题栏右上角统一使用 X 关闭按钮，长内容滚动时标题栏保留可见；不再使用底部返回或继续游戏按钮关闭弹窗，设置中的“返回标题”仍作为页面导航。

## 校园地图

Phaser 负责俯视二维像素世界，使用 WebGL 绘制；React 管理页面、表单、菜单和游戏实例挂载，不驱动逐帧模拟。游戏模块仅在浏览器按需加载，离开游戏时销毁实例和监听器。

开发区校区地图固定北朝上，以 WGS84 资料生成 1 米地面格。地面和植被模块使用原生 16×16 PNG，湖岸和步道保留斜向连接及朝向一致的岸坡。建筑为独立透明整图，画布边长为 16 的整数倍，像素密度与地面一致，落地点、占地和前后遮挡仍由真实网格决定；建筑不强拆成一米重复立面块。七舍的 DUT 标识面在当前视角不可见，不绘制、不旋转楼体展示它。来源与误差见[地图生成](map-generation.md)。

主画面使用上述世界显示倍率，未创建人物时以涌泉湖北岸的登记焦点为中心，创建后跟随人物。横纵方向中央 50%（25%–75%）为镜头静止区，越界后镜头仅移动到角色回到区间边缘，地图边界优先。不支持拖拽平移或滚轮缩放。按 M 打开地图窗口。每个 1 米瓦片保留 16×16 原始像素，显示边长为 16q 个物理像素；建筑与植被使用相同像素密度。窗口尺寸与全屏状态变化时重算静止区，有人物时以人物重新定位，无人物时保留登记焦点，按 64×64 米分块创建多层瓦片和植被，离开视野后释放。

游戏 HUD 左上方显示圆形像素小地图，右上方显示设置按钮，不显示右下角来源标识。设置按钮使用缝合像素字体的 U+2699 齿轮字形，沿用 PixelText 原生栅格化，不使用系统彩色 emoji。底部 I 入口只提供背包。地图数据的 OSM 署名及许可集中在首页“关于”，从游戏设置中的“返回标题”可以到达。

点击齿轮或按 Escape 打开设置，设置提供小、标准、大三档界面尺寸、进入或退出全屏和返回标题。弹窗使用 Radix Dialog 管理模态交互、焦点限制、关闭后的焦点恢复及 Escape 关闭，点击遮罩或右上角 X 也可关闭。弹窗只提供标题，不添加重复说明文字。全屏请求失败时在设置中显示反馈，不添加无实际功能的音量或画质选项。

加载时显示底部进度条，不叠加技术说明、地区介绍或调试文本。加载失败显示错误；地图支持本地人物移动与基础碰撞，尚无联机会话。

## 后续游戏交互

优先建设有参考资料支持的小范围校园。采用统一像素网格、角色比例和遮挡规则，地面碰撞与装饰分离。昼夜、局部光晕、天气粒子和着色器服务于校园氛围；实时遮挡阴影在明确需求与性能验证后引入。

移动、朝向、失焦停止、暂停与恢复需同时考虑键盘和触屏。客户端预测与插值不改变后端权威状态；断线时停止发送移动，并明确显示连接状态。

## 边界

当前提供固定倍率的人物跟随视图、设置、简化建筑外观和有来源的植被分布，以及账号、角色创建和背包穿脱，不包含室内或 WebRTC 游戏同步。Next.js 不提供服务端 API 或实时游戏模拟。

## 大地图窗口

M 打开标题为“地图”的居中窗口，M、Escape、点击遮罩或右上角 X 关闭。校园画面在窗口后保留，模态窗口打开时停止移动；输入框内的 M 不触发地图，已有其他模态窗口时不叠加地图，Escape 关闭地图不再打开设置。

地图原图为 128×148 PNG，每个原生像素表示 10 米，北朝上。使用界面显示倍率与最近邻显示，不调整浏览器缩放；小屏保留原生像素密度并允许窗口滚动。人物位置按世界像素坐标除以 160 映射至地图，打开时取快照；建筑命中区域由真实占地换算，悬停、聚焦或点击显示名称。原图以真实材质网格和建筑为 imagegen 参考，再由 tools/prepare_world_map.py 最近邻缩小并量化为 64 色。美术简化不改变地面通行与碰撞数据，生成来源见 references/eda/world-map.json。

点击建筑后保持选中高亮与名称，底部“快速前往”在有角色且已选建筑时可用。前往时以真实建筑占地南侧室外地面为起点，在 32 米范围内寻找通过现有角色通行判定的落点；这不是对建筑入口位置的推断。成功后清空移动输入、更新人物深度和镜头中心并关闭地图；无可行走落点时保留原位置和地图并显示反馈。当前为本地传送，未来联机时由服务端确认。

## 实时小地图

左上角为原生 64×64 圆形像素画布，北朝上，每个缩略像素对应 2 米，显示人物周围约 128 米范围。底图从现有地面材质与真实建筑占地生成，不使用示意大地图美术；人物居中，并标记朝向。没有角色时显示登记焦点且不绘制玩家标记。位置以最多每秒 10 次检查，只有取整位置、朝向或角色存在状态改变时重绘；不通过 React 逐帧更新。人物移动、快速前往和退出账号均更新显示。圆形遮罩与边框在原生像素逐点生成，alpha 只取 0 或 255，跟随界面显示倍率。点击小地图打开已有地图窗口，其他模态窗口打开时不叠加。背包入口统一通过底部 I 按钮访问。

## 环境动画

环境动画使用 PNG 图集与 apps/web/public/campuses/eda/animations/manifest.json，不使用 GIF。水面图集由 tools/generate_environment_animations.py 从现有原生瓦片生成，每帧 16×16，每种水面 16 帧、每帧 120 毫秒循环；只移动水域内部的波纹，透明范围、草岸、接触阴影和岸坡保持静止。清单记录图集路径、帧宽高、每帧时长和各瓦片的帧索引，可独立调整播放速度。

树木沿用已有贴图，用清单中的整数位移序列与 220 毫秒步长表达微风；树实例 ID 决定相位。树冠水平偏移最多一个原生像素，底部 32 原生像素及跨越该边界的合并块固定，矮灌木不摆动。禁止旋转、非整数缩放或位移。动画仅遍历可见容器登记的动画部件，水面只在帧号变化时切换帧；离开视野后随容器销毁。动画不改变地图数据、角色通行和碰撞，现有窗口仅暂停玩家输入，环境继续播放。

## 遮挡与半透明

人物以脚底落点排序；树木以登记根部落点排序。建筑按真实 footprint 的逐列交点计算局部南向落地边缘，不使用整张 PNG 的底边或包围盒底边统一排序。原图按 8 个原生像素（0.5 米）宽的竖条计算投影区段，凹形和复合占地按同列的多个区间分别处理，接触深度相同且连续的裁片合并。渲染裁片复用同一张建筑纹理，完整覆盖原图且无重叠，不新增 PNG 或改变外观、占地和碰撞。圆形及倾斜边缘保留原轮廓，深度精度受竖条宽度与既有占地资料限制。

只有处于人物前方的实际不透明像素与人物当前帧不透明像素重叠时，对应建筑或植被物件才降为 45% 不透明度；人物走到前方、离开遮挡或退出账号时恢复。透明度按帧耗时平滑变化，完整淡出或恢复各需 180 毫秒，中途进出遮挡时从当前透明度反向过渡，同一建筑的所有裁片同步变化。透明留白、单纯包围盒相交及人物自身透明像素不触发。树冠检测使用当前风摆位置，灌木同样参与；遮挡只改变显示透明度，不允许穿过实体。建筑裁片独立参与世界深度排序，离开视野时统一销毁。

## 背包界面

移除左上“角色”按钮，使用底部 `I` 按钮或键盘 `I` 打开背包；账号与角色创建仅在首页处理。背包窗口将五个装备槽紧贴人物预览两侧排列，空槽用淡色图标标明部位；背包保留固定 3×10 背包格、下方独立 1×10 物品栏，共四行格子；容量来自服务端，未解锁格保留锁定占位图。底部快捷栏对应独立物品栏的 10 格，始终可用，数字键 `1`–`0` 切换。槽位参考 Minecraft 的内凹明暗边框和外部选中框，全部为正方形：常规尺寸 24×24 原生像素，窄屏为 20×20；背包、装备、物品栏和底部 I 按钮共用同一尺寸。空格仅保留槽面，锁定格保留锁图案。物品图标为原生 16×16 像素画布，人物仍为原生 16×32，边框为一个共享像素，显示倍率沿用所选界面尺寸，与实际校园地图独立。容量、穿脱与位置规则见[角色外观与穿戴](characters.md)。

首页始终提供文字“设置”按钮；首页和游戏内复用 `components/game-settings.tsx` 及其样式，均可调整界面尺寸和全屏。首页设置不显示“返回标题”，Escape 仅关闭已有窗口，不在首页直接打开设置；游戏内保留齿轮入口和 Escape 打开设置。

## 进入校园与身份认证

首页加载时若本标签页保存了账号令牌，先调用 auth-refresh 验证并续期以恢复菜单登录状态，不自动打开窗口或加载校园。未登录主按钮显示“登录”，不显示“账号”；注册、密码或统一认证登录成功后关闭登录窗口并停留首页，主按钮改为“进入校园”，同时显示“账号”。点击“进入校园”后验证当前会话，读取物品定义与角色；没有角色时在首页窗口完成名字、性别、捏脸与初始衣物选择，名字与性别按服务端 defaults 预填并可修改；角色准备成功才导航到 `/game/`。“账号”按钮提供独立的首页账号管理入口，显示角色用户名、注册邮箱及统一认证绑定状态，未绑定时提供绑定按钮，并可退出登录、清除本标签页会话；已有角色不会在管理入口登录后自动跳走。没有角色时也可以在创建表单中先绑定统一认证，再使用 preferred_username 与性别预填。

首页将已验证的 PocketBase 令牌、角色与物品定义保存在本标签页 `do-game-session` 启动快照中，`do-session` 保留登录令牌供下次首页进入使用。campus 不显示登录或创建表单、不执行 auth-refresh 或 OAuth；缺少准备好的启动快照时直接返回首页，并且不启动 Phaser。地图就绪时立即加载已准备的角色，背包直接使用同一快照，成功换装后更新快照以供刷新恢复。受保护的背包接口仍由服务端验证账号；返回 401 时清除本地会话并回到首页，不在游戏内续期或弹出登录。

启动快照格式版本为 2，增加角色性别；旧快照返回首页重新准备，不在游戏中推测补齐。启动快照只用于当前本地行走与持久化背包，不是服务端签发的联机票据，也不是授权依据。WebRTC 接入尚未实现：后续应在首页通过已验证账号申请短期游戏票据，campus 使用游戏票据建立连接；信令、准入和失效退出规则见[多人通信](networking.md)。

## 统一身份认证入口

首页账号窗口从 `users/auth-methods` 读取已启用的 OIDC 提供商，配置生效后显示“大工统一认证”按钮。调用 PocketBase 官方 SDK 的 `authWithOAuth2` 新标签页流程，使用内存 BaseAuthStore；成功后只将 PocketBase 用户令牌保存到本标签页的 `sessionStorage`，复用已有角色读取与创建流程，不额外使用 SDK 默认的 localStorage 会话。保留邮箱密码登录，用户名不能用于密码登录。SSO 登录已绑定身份时直接登录；未绑定时在首页账号弹窗中完成注册或绑定已有账号，使用同一次认证结果，不再次要求学校认证。绑定时将当前本地账号令牌装入同一个内存 BaseAuthStore 后调用 authWithOAuth2，保存返回的新 PocketBase 令牌并刷新账号绑定状态与角色默认值；不在游戏页面绑定或恢复登录。错误沿用首页账号窗口反馈。

统一认证在用户点击时同步打开普通 `_blank` 标签页，不指定弹窗尺寸、位置或浏览器工具栏特征；通过 SDK urlCallback 导航到授权地址，保留首页等待结果。授权标签页与首页断开 opener，仍沿用 PocketBase 的一次性回调订阅返回结果，结束后关闭授权标签页；登录和绑定共用同一打开方式。

首次 SSO 未绑定时，首页账号弹窗直接切换为注册引导，票据保存在本标签页 sessionStorage 的 do-sso-onboarding-ticket，不放入 URL；刷新后恢复弹窗并向后端检查有效期。服务端提供浏览器 Cookie 证明，页面不读取或自行构造学校身份。

首页弹窗默认显示“完成统一认证注册”，可以切换“已有账号”；按钮分别为“注册并绑定”和“登录并绑定”，不显示再次进行 SSO 的入口。邮箱注册要求验证码及确认密码，密码登录使用 PocketBase；拿到本地账号令牌后消费引导票据，关闭弹窗并显示“进入校园”。取消引导清除本标签页凭据；过期或其他浏览器打开时显示失效反馈，禁止提交。引导票据不替代登录令牌，创建角色和进入校园仍遵循首页准备流程。
