> 后续策略：整校区细节包已由 campus-grid-streaming 接替。以下保留原变更设计背景，当前网格行为以新变更规范为准。

## Context

动机见 proposal.md。当前单个 Web PCK 包含全部校区，开发区模型约占 51 MB；桌面需保持离线可用，编辑器中完整静态模型必须保留。

## Goals / Non-Goals

**Goals:** 减少 Web 首包，首次传送按校区下载，失败可恢复。

**Non-Goals:** 校园内部网格切分、几何优化、新建筑、多人联网、WASM 分块。

## Decisions

- Web 导出预设仅显式包含凌水与共享逻辑。原生导出插件将开发区和盘锦场景及其校区专属资源制成独立 PCK，写入带大小、SHA-256 和哈希文件名的清单；桌面预设保持不变。
- 开发区模型序列化为压缩二进制场景，包内提供原路径重映射，保留节点、Feature ID、材质与碰撞逻辑。原始 TSCN 不改动。
- 资源加载器只读获取页面资源基址（JavaScriptBridge 单次读取 location），原生 HTTPRequest 使用完整同源 URL 下载到 user:// 临时文件，验证大小和哈希后挂载；已挂载包同一会话复用。下载期间保留旧校区，冻结行走并释放鼠标，地图内显示进度、错误、重试与取消。成功后再切换场景，校区到达直接继续探索，不显示进入按钮。
- 超时、HTTP 错误或校验失败保持原场景，可重试或取消。取消释放请求并清除临时文件。校区切换后释放旧节点，已挂载 PCK 保留至会话结束，后续传送无需再次下载；不保证跨页面重载的持久离线缓存。

## Risks / Trade-offs

- Godot WASM 约 40 MB 仍需完整下载 → 分别报告引擎与首包大小，不承诺瞬时启动。
- 首次进入开发区需下载并实例化完整校园 → 提供真实进度；保留完整校园以避免网格边界和物体突然出现。
- 部署新版本时旧页可能请求旧包 → 使用内容哈希避免混用；缺失时保留原场景并可取消或刷新。
- PCK 无卸载接口 → 仅声明卸载旧校园实例，同一会话的下载包继续保留。

## Migration Plan

Web 导出目录新增 campuses/，部署须整体携带该目录；现有 Docker COPY 已包含整个 Web 目录。回滚时使用上一提交重新导出的完整产物，不能混用清单与资源包。
