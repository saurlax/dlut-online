# 前端与像素世界

## 当前入口

Next.js 以 SSG 模式生成产品入口、`/campus/` 校园地图和静态 404 页面。页面语言为简体中文，保留字体默认字间距，不引入外部字体请求。首页通过“进入校园”打开地图；首页与游戏之间使用原生链接做整页切换，不依赖静态服务器上的 RSC 分段预取重写。

界面使用本地托管的缝合像素字体，选择 12px 简体中文比例版。所有可见文字，包括按钮、设置标题、错误和来源署名，使用同一原生字号，不使用合成粗体或斜体，保留默认字距。文字先在 12px 画布中以基线 10 栅格化，alpha 规整为 0 或 255，再随界面整数放大；DOM 保留原文供读屏与按钮名称读取。字库及 OFL 授权文件随静态资源发布，字体来源记录在 `CREDITS.md`。

## 显示像素网格

`game/pixel-grid.ts` 统一计算显示单位，以一个原生像素约占 2 CSS 像素为显示基准。设浏览器 `devicePixelRatio` 为 d，一个原生像素占 `q = max(1, round(2 × d))` 个物理像素，对应 `q / d` 个 CSS 像素。DPR 为 1、1.25、1.5、2、3 时，q 分别为 2、3、3、4、6。分数 DPR 下按整数物理像素取整。DPR 不是显示器真实 PPI；如需换算毫米，使用 `25.4 × q / PPI`，不能仅凭 DPR 推导。

瓦片、建筑、植被、16×16 图标、12px 字体、按钮边框、高光、阴影、焦点框、间距、加载条和首页背景服从此网格。首页 Logo 独立以原始 320×160 的固定 CSS 尺寸显示，不随视口或 DPR 调整尺寸。地图保持原生分辨率渲染，界面按一个原生像素等于一个布局像素排版，再以共享倍率从左上角映射到屏幕。弹窗宽高和居中位置对齐整数网格，不直接给 CSS 边框设置小数宽度；按钮按压只移动一个完整原生像素，不使用连续位移动画。

窗口和全屏尺寸变化只改变可见范围；DPR 变化时重新计算共享倍率并更新画布及界面，包括移动到不同缩放率的显示器。最右和最下不足一格的区域裁切，不拉伸最后一格。Phaser 的相机倍率为 1，画布最近邻放大，不叠加第二次相机缩放。

界面通过名称、层级和布局传达用途，不默认配套说明段落、副标题或提示卡。`description` 等说明组件仅用于用户操作和决策必需的信息；具体文案约定见 [开发约定](../DEVELOPMENT.md#界面与文案)。

按钮与链接复用 `components/game-button.tsx` 和同目录样式，使用大工蓝与书页白。按钮及窗口的外轮廓为一原生像素，按钮仅保留一像素高光、下沿阴影和按压位移，不叠加第二层内框、铆钉或厚色带。像素格对齐与线条重量分别核对，不能以同网格为由默认两像素描边与地图一像素细线具有相同颗粒感。文字按钮默认不配图标，文字居中且不保留图标占位；设置入口保留简化的线框齿轮，弹窗标题只显示文字。书籍与禾苗意象保留在固定 Logo 中。交互复杂度由按需引入的 Radix Primitives 承担，设置与关于使用 Dialog 并共享 `components/game-dialog.css`；视觉由项目样式控制，不引入整套通用视觉主题。

首页采用游戏标题画面：蓝色 DLUT Online 标志结合书籍与幼苗意象，背景为沿主楼中轴线正视主楼与毛泽东像的横向像素插画。标题放在上方天空，前景纵向放置“进入校园”和“关于”，保持地标可见，不添加介绍卡片或尚不可用的菜单入口。窄屏裁切同一横向插画，横屏低高度时按钮移到右下方。

“关于”集中展示 OpenStreetMap 数据署名及 ODbL 许可、缝合像素字体及 OFL、项目美术与实景和风格参考、Radix 及 MIT 许可，来源与 `CREDITS.md` 保持一致，提供可访问的来源和许可链接。弹窗沿用像素字体及共享显示网格，长内容可滚动，滚动位置对齐原生像素，底部返回按钮保持可见；支持 Escape、点击遮罩关闭和焦点恢复。界面按逻辑视口收紧窄屏和低高度布局，长版权文字在原生画布内换行，保持相同字形网格与原始可访问名称。不在地图画面叠加版权署名。

标题插画使用 imagegen 生成，再通过 `tools/prepare_title_assets.py` 最近邻采样并规整调色板。正式背景为 512×288、最多 64 色，透明标志为 320×160、最多 40 种可见颜色且 alpha 仅取 0 或 255。标志直接作为固定 320×160 CSS 像素的图片居中显示，不放进背景画布、不在窗口变化时重新采样或放大。背景单独以最近邻采样到共享网格的原生画布，再按统一倍率显示；不加载生成时的大图或实景照片。来源、提示词与像素处理约定记录在 `references/branding/title-screen.json`。首页插画独立于地理网格，不作为地图几何依据。

## 校园地图

Phaser 负责俯视二维像素世界，使用 WebGL 绘制；React 管理页面、表单、菜单和游戏实例挂载，不驱动逐帧模拟。游戏模块仅在浏览器按需加载，离开游戏时销毁实例和监听器。

开发区校区地图固定北朝上，以 WGS84 资料生成 1 米地面格。地面和植被模块使用原生 16×16 PNG，湖岸和步道保留斜向连接及朝向一致的岸坡。建筑为独立透明整图，画布边长为 16 的整数倍，像素密度与地面一致，落地点、占地和前后遮挡仍由真实网格决定；建筑不强拆成一米重复立面块。七舍的 DUT 标识面在当前视角不可见，不绘制、不旋转楼体展示它。来源与误差见[地图生成](map-generation.md)。

主画面使用上述共享显示倍率，未创建人物时以涌泉湖北岸的登记焦点为中心，创建后跟随人物。横纵方向中央 50%（25%–75%）为镜头静止区，越界后镜头仅移动到角色回到区间边缘，地图边界优先。不支持拖拽平移或滚轮缩放。按 M 打开地图窗口。每个 1 米瓦片保留 16×16 原始像素，显示边长为 16q 个物理像素；建筑与植被使用相同像素密度。窗口尺寸与全屏状态变化时重算静止区，有人物时以人物重新定位，无人物时保留登记焦点，按 64×64 米分块创建多层瓦片和植被，离开视野后释放。

游戏 HUD 左上方显示圆形像素小地图与其右侧角色入口，右上方显示设置按钮，不显示右下角来源标识。设置按钮使用缝合像素字体的 U+2699 齿轮字形，沿用 PixelText 原生栅格化，不使用系统彩色 emoji。角色入口提供账号、创建预览、背包及穿脱。地图数据的 OSM 署名及许可集中在首页“关于”，从游戏设置中的“返回标题”可以到达。

点击齿轮或按 Escape 打开设置，设置提供进入或退出全屏、返回标题和继续游戏。弹窗使用 Radix Dialog 管理模态交互、焦点限制、关闭后的焦点恢复及 Escape 关闭，点击遮罩或继续游戏也可关闭。弹窗只提供标题，不添加重复说明文字。全屏请求失败时在设置中显示反馈，不添加无实际功能的音量或画质选项。

加载时显示底部进度条，不叠加技术说明、地区介绍或调试文本。加载失败显示错误；地图支持本地人物移动与基础碰撞，尚无联机会话。

## 后续游戏交互

优先建设有参考资料支持的小范围校园。采用统一像素网格、角色比例和遮挡规则，地面碰撞与装饰分离。昼夜、局部光晕、天气粒子和着色器服务于校园氛围；实时遮挡阴影在明确需求与性能验证后引入。

移动、朝向、失焦停止、暂停与恢复需同时考虑键盘和触屏。客户端预测与插值不改变后端权威状态；断线时停止发送移动，并明确显示连接状态。

## 边界

当前提供固定倍率的人物跟随视图、设置、简化建筑外观和有来源的植被分布，以及账号、角色创建和背包穿脱，不包含室内或 WebRTC 游戏同步。Next.js 不提供服务端 API 或实时游戏模拟。

## 大地图窗口

M 打开居中的校园地图窗口，M、Escape、点击遮罩或返回关闭。校园画面在窗口后保留，模态窗口打开时停止移动；输入框内的 M 不触发地图，已有其他模态窗口时不叠加地图，Escape 关闭地图不再打开设置。

地图原图为 128×148 PNG，每个原生像素表示 10 米，北朝上。使用共享显示倍率与最近邻显示，不调整浏览器缩放；小屏保留原生像素密度并允许窗口滚动。人物位置按世界像素坐标除以 160 映射至地图，打开时取快照；建筑命中区域由真实占地换算，悬停、聚焦或点击显示名称。原图以真实材质网格和建筑为 imagegen 参考，再由 tools/prepare_world_map.py 最近邻缩小并量化为 64 色。美术简化不改变地面通行与碰撞数据，生成来源见 references/eda/world-map.json。

点击建筑后保持选中高亮与名称，底部“快速前往”在有角色且已选建筑时可用。前往时以真实建筑占地南侧室外地面为起点，在 32 米范围内寻找通过现有角色通行判定的落点；这不是对建筑入口位置的推断。成功后清空移动输入、更新人物深度和镜头中心并关闭地图；无可行走落点时保留原位置和地图并显示反馈。当前为本地传送，未来联机时由服务端确认。

## 实时小地图

左上角为原生 64×64 圆形像素画布，北朝上，每个缩略像素对应 2 米，显示人物周围约 128 米范围。底图从现有地面材质与真实建筑占地生成，不使用示意大地图美术；人物居中，并标记朝向。没有角色时显示登记焦点且不绘制玩家标记。位置以最多每秒 10 次检查，只有取整位置、朝向或角色存在状态改变时重绘；不通过 React 逐帧更新。人物移动、快速前往和退出账号均更新显示。圆形遮罩与边框在原生像素逐点生成，alpha 只取 0 或 255，跟随共享显示倍率。点击小地图打开已有地图窗口，其他模态窗口打开时不叠加。角色按钮移至小地图右侧。

## 环境动画

环境动画使用 PNG 图集与 apps/web/public/campuses/eda/animations/manifest.json，不使用 GIF。水面图集由 tools/generate_environment_animations.py 从现有原生瓦片生成，每帧 16×16，每种水面 16 帧、每帧 120 毫秒循环；只移动水域内部的波纹，透明范围、草岸、接触阴影和岸坡保持静止。清单记录图集路径、帧宽高、每帧时长和各瓦片的帧索引，可独立调整播放速度。

树木沿用已有贴图，用清单中的整数位移序列与 220 毫秒步长表达微风；树实例 ID 决定相位。树冠水平偏移最多一个原生像素，底部 32 原生像素及跨越该边界的合并块固定，矮灌木不摆动。禁止旋转、非整数缩放或位移。动画仅遍历可见容器登记的动画部件，水面只在帧号变化时切换帧；离开视野后随容器销毁。动画不改变地图数据、角色通行和碰撞，现有窗口仅暂停玩家输入，环境继续播放。

## 遮挡与半透明

人物以脚底落点排序；树木以登记根部落点排序。建筑按真实 footprint 的逐列交点计算局部南向落地边缘，不使用整张 PNG 的底边或包围盒底边统一排序。原图按 8 个原生像素（0.5 米）宽的竖条计算投影区段，凹形和复合占地按同列的多个区间分别处理，接触深度相同且连续的裁片合并。渲染裁片复用同一张建筑纹理，完整覆盖原图且无重叠，不新增 PNG 或改变外观、占地和碰撞。圆形及倾斜边缘保留原轮廓，深度精度受竖条宽度与既有占地资料限制。

只有处于人物前方的实际不透明像素与人物当前帧不透明像素重叠时，对应建筑或植被物件才降为 45% 不透明度；人物走到前方、离开遮挡或退出账号时恢复。透明留白、单纯包围盒相交及人物自身透明像素不触发。树冠检测使用当前风摆位置，灌木同样参与；遮挡只改变显示透明度，不允许穿过实体。建筑裁片独立参与世界深度排序，离开视野时统一销毁。
