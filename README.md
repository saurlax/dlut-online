# DLUT Online

**在熟悉的校园，遇见新的故事。**

DLUT Online 是一个以大连理工大学为背景的第一人称校园 MMORPG 项目，面向浏览器，探索校园生活与多人互动的更多可能。

从凌水主校区到开发区校区，再到盘锦校区，我们希望把散落在不同地方的校园记忆，连接成一个可以走进、停留和相遇的世界。沿着熟悉的道路漫步，重新看看曾经匆匆路过的建筑，也去认识另一座校区的风景。

校园的故事还在人与人之间。我们希望以各个社团的特色为灵感，将棋牌对弈、服装搭配和校园趣味活动融入这个世界，让共同的兴趣成为相识的起点。独自闲逛，或与朋友一起参与其中，都是我们想呈现的校园生活。

我们以真实地图与实景照片为参考，追求自然、写实的校园氛围，让建筑、道路与日常生活共同构成这个世界。

## 当前版本操作

点击游客登录后，WASD 行走，Shift 奔跑，鼠标环视，空格跳跃（仅落地时起跳，按住不连跳）。M 或点击小地图打开地图，M/Escape 收起；Escape 暂停，点击世界或 Escape 恢复，失焦停止控制。

游客 ID 为随机生成的 128 位标识，保存在浏览器 `sessionStorage` 的 `do_guest_id` 中，昵称为“游客”加六位数字。同会话刷新、暂停和校区传送保留身份；新会话重新生成，复制标签和恢复关闭页面遵循浏览器会话存储行为。桌面身份只保留在当前进程。存储受限时封面提示重试。

同校区玩家通过 `/ws` 每秒同步 10 次位置和朝向，远端使用简洁人形代理和昵称，自己的角色保持第一人称。切换校区和断线会清理远端角色，普通网络中断自动重连，连接状态可在地图查看。同一 ID 新连接会替换旧连接，旧页面停止重连。当前为客户端位置上报，不含持久账户、服务端防作弊、角色定制或玩家间碰撞；游客 ID 不是鉴权凭证。

浏览器加载页显示已加载 / 总资源量（MB）及百分比，1 MB = 1,000,000 字节；计数来自 Godot 的 WASM/PCK 加载进度，不代表压缩后的网络流量，下载完成后仍可能需要等待引擎初始化。

## 桌面服务器配置

编辑器 F5/F6 或直接运行项目时，默认 `DO_ENV=development`、`DO_SERVER_URL=http://localhost:8060`。Windows/macOS 导出（包括调试导出）默认使用 `production` 和 `https://dlut.online`；项目已启用原生导出插件，编辑器导出和 CI 均会自动将这两个值写入包内，不生成工作区配置文件。

在仓库根目录可这样覆盖本地配置：

```sh
DO_SERVER_URL=http://localhost:9000 godot --path apps/client
```

默认发布导出无需额外变量，也可显式指定。先确保输出目录存在：

```sh
mkdir -p apps/client/build/macos
DO_ENV=production DO_SERVER_URL=https://dlut.online \
  godot --headless --path apps/client --export-release macOS 'build/macos/DLUT Online.zip'
```

将导出命令中的 `DO_ENV` 改为 `development` 并移除 `DO_SERVER_URL`，可生成默认指向 localhost 的测试包。Windows 使用 `Windows` 预设与 `.exe` 输出路径。

桌面客户端运行时也接受进程环境变量覆盖。优先级为：显式 `DO_SERVER_URL` > 显式 `DO_ENV` 对应的默认地址 > 包内配置。空变量视为未设置；`DO_ENV` 只接受 `development` / `production`。服务器地址须为 HTTP(S) 根地址，不含接口路径，末尾斜杠会移除。不自动加载 `.env`；已打开的编辑器需要重启才能继承新设置的环境变量。

桌面联网通过 `preload("res://scripts/desktop_config.gd").read()` 获取服务器根地址，并连接对应 `/ws`。Web 不注入桌面配置，使用页面同源 WebSocket 地址，HTTPS 页面自动使用 WSS。

## Web 校区资源包

Web 首包只包含默认凌水校区和共享资源。首次在地图选择开发区或盘锦时，游戏下载对应完整校区包，显示 MB 进度；下载成功后直接传送。失败可重试，取消或按 M/Escape 收起地图会终止下载并留在原校区。同一页面会话内再次进入已加载校区无需重复下载。

校区内部仍是完整场景，没有网格切分或几何删减。Windows/macOS 包继续包含全部校区，支持离线切换；编辑器静态场景保持原样。WASM 仍需首次完整下载，启动页 MB 只统计首包必需资源，其他校区在传送时单独计数。

已启用原生校区导出插件，正常 Web 导出会自动生成 `build/web/campuses/` 下带内容哈希的 PCK 和首包内的清单。部署须上传整个 Web 导出目录，不能仅复制 index 文件；Go 静态服务与 Docker 已按整个目录提供资源。资源加载器只读获取浏览器页面基址，下载、校验、进度与传送均使用 Godot 原生节点；不会使用桌面 `DO_SERVER_URL` 来选择校区资源域名。

校区包进行大小与 SHA-256 校验，下载超时为 120 秒。同一会话已挂载包保留到页面退出，离开校区会卸载该校园实例；不保证刷新后的持久离线缓存。部署新版本后，旧页面遇到缺失的旧版资源包可刷新再试。
