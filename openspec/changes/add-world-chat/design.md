## Context

现有 GameNetwork Autoload 跨校区保留原生 ENet 连接；`GameProtocol` 当前版本为 4，控制消息在通道 0 可靠发送，未知消息会被服务端拒绝。服务端 `players` 以 PocketBase ID 维护在线身份，`identity.username` 来自票据验证后的玩家显示名，区别于右下角 HUD 的账号 `username`。地图与登录、传送覆盖层由现有 HUD 管理。

## Goals / Non-Goals

**Goals:** 实现同服务器世界交流、准确进出通知、左下角原生聊天交互和严格的每秒发送限制，保持第一人称控制及跨场景连接规则。

**Non-Goals:** 不增加持久化、跨服务器广播、其他频道或无关 UI；本轮仅做规范。

## Decisions

### 服务端权威消息与在线事件

聊天请求只提交消息文本与当前连接内的请求序号；姓名、玩家 ID、消息类别和事件序号由服务端生成。名称沿用已验证的 `identity.username`，不改账号字段语义。使用通道 0 的可靠有序消息承载请求、广播和发送结果；仅服务端可生成系统进出事件。事件序号在当前服务器进程内递增，客户端按连接清理去重状态，切图保留。

世界广播遍历同实例全部已准入且未关闭的连接，包括发送者和正在切图的玩家；不按校区过滤，不沿用同校区 roster 推断进出。准入成功并完成 welcome 后广播加入；实际移除在线身份时广播离开，重复关闭回调不得重复发送。同账号连接替换视为在线身份延续，不广播离开/加入；真实离线后重新准入则分别广播。

当前版本 4 服务端会拒绝新消息，因此后续实现把共享协议升级为 5，客户端和游戏服一起发布。规范 PR 本身不改版本；既有 ENet/DTLS、输入和快照规则不变。

### 严格的 1000 ms 间隔

客户端按单调时钟记录最近提交时间，首次可立即发送；提交后至少 1000 ms 才允许下次提交。冷却期间回车不提交、不清空、不关闭输入、不排队。客户端只有一个待确认请求，避免未确认文本丢失；成功广播到达后清空草稿并恢复进入输入前的控制状态，拒绝则保留草稿。

服务端按账号 ID 记录最近接受时间，在验证文本和身份后执行 `now - last_accepted >= 1000 ms`。恰好 1000 ms 可以接受，不能用每个自然秒清零的计数器或累计令牌造成突发。拒绝、空消息和无效消息不推进接受时间；限流拒绝返回剩余冷却时间，客户端据此延后可发送时间，不立即重试。短暂断开/同账号换连接不能重置冷却；离线记录在冷却过期后可回收，避免无界增长。每名账号的首次有效消息可立即接受。

### 文本与记录边界

去掉首尾空白后，正文为 1–200 个 Unicode 码点且 UTF-8 不超过 800 字节；拒绝换行、回车及其他控制字符，空白消息不发送。客户端和服务端采用相同校验，保留既有控制包大小与滥用保护。聊天和名称均作为纯文本渲染，不解析 BBCode/富文本；名称中的换行及控制字符替换为空格，不能伪造额外行或系统通知。正文长行按宽度自动换行。

客户端在 GameNetwork 中保留最近 100 条消息事件（不是 100 个视觉行），只占内存；新消息自动滚到最新，超出移除最旧事件。不新增历史拉取或历史浏览控件。切图和地图覆盖期间继续接收；换服、退出、断线结束会话或认证失效时清空消息和草稿，避免跨会话泄漏。不本地预先回显，再由广播追加第二次。

### 原生左下角布局与输入

复用现有 HUD，以 Godot 原生 Control 实现记录区与仅编辑时显示的输入框。左侧 16 px、底部 24 px 逻辑留白作用于整个聊天组件，包括输入框；默认宽度 420 px、记录区最大高度 200 px，并在小窗口内收缩。白色 `#FFFFFF` 用于完整玩家消息，黄色 `#FFFF00` 用于完整进出提示，采用文字阴影保证明暗背景可读，保持默认字间距。未编辑时不抢键盘焦点，记录区不拦截点击世界。

校园画面可交互时按回车打开输入，停止行走和环视、释放鼠标；输入中的 WASD、M 等按键仅输入文本，不触发移动或地图。中文输入法确认候选的回车不能同时发送。Escape 取消编辑并保留草稿，恢复编辑前的暂停/鼠标状态；失焦停止控制但不自动发送，回到窗口不强制恢复行走。登录、全屏地图、传送覆盖层期间隐藏聊天，禁止打开输入；恢复校园后显示缓存，不自动获取焦点。暂停时仍可接收消息。

## Risks / Trade-offs

- [同账号替换触发既有 remove_player 路径] → 实现时明确区分替换和离线，并检查旧连接迟到回调，不能简单在所有移除函数中无条件广播。
- [网络延迟导致客户端冷却与服务端到达间隔不同] → 服务端最终判定，拒绝保留草稿并同步剩余时间，不自动补发。
- [中文输入法与第一人称控制冲突] → 桌面实际检查输入法回车、Escape、失焦和地图操作；必要时补充字体子集。
- [可靠广播增加排队] → 单条文本、频率与客户端记录均有界，沿用慢连接保护，不影响实时输入通道。

## Migration Plan

本 PR 无运行发布或迁移。后续实施完成后共同发布协议 5 的桌面客户端与游戏服，旧版本由版本握手明确拒绝；回滚需共同回滚兼容版本。执行相关本地协议和双真实账号联调、字体与渲染检查、Windows/macOS 客户端及 Linux 游戏服导出，不运行 Web 导出，不改校园模型和碰撞。
