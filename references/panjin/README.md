# 盘锦校区建模依据

读取日期：2026-09-14。来源为用户指定的 [大连理工大学官方地图](http://map.dlut.edu.cn)。校区对象 ID 77299，原点为 `references/campuses.json` 中的 (122.12445312006, 40.6862493884607)。

## 官方布局与范围

`bounds.json` 归档 [公开轮廓接口](http://map.dlut.edu.cn/openmap/mapi/bd/v1/bound) 中所有顶点位于经度 (122.10,122.15)、纬度 (40.67,40.71) 的 73 条记录。全站原响应共 550 条，`source_index` 为全站原始零起算位置；筛选框不是校区红线。

排除衍中街以南的盘锦奥体中心、体育中心、附属田径场及四处停车场共 9 条，具体 ID 和原因见 `excluded.json`。本次不把这些周边设施建成校园。保留 60 个 Feature ID、64 段轮廓：49 段建筑、9 段道路、3 段停车场、2 段校门地面，以及 1 个彩虹长廊来源节点。同 ID 多段道路全部保留，节点命名为 `Feature_<id>_<part>`。

坐标沿用源站未声明坐标系，以纬度余弦转为近似米制，X 向东、Z 向南。模型底座为保留轮廓外包框加 30 米，不是官方红线；地面没有实测高程。官方二维轮廓不等同于实测首层基底，不擅自修正轮廓、挖庭院或补入口。

## 照片支持的局部外观

`photos/<id>.json` 保存完整请求 URL、读取日期和照片对象 ID、原始 imageURL。图片地址为 `http://map.dlut.edu.cn` 加 imageURL；本地文件序号为接口 result 的零起算位置。五张实际使用照片仅作离线参考，不在 Godot 资源目录内、不进入桌面导出包。其他已查看对象只保留 JSON 索引。

`facades.json` 声明具体边索引、照片用途与精度限制。边索引以去除闭合重复点的原始轮廓零起算。相对方位通过相邻建筑关系核对，不是相机标定结果。

| 对象 ID | 建筑 | 已制作的照片可见部分 | 估算高度 |
|---|---|---|---|
| 77963 | E01 图书馆 | 西侧与南侧曲面浅金色竖片、窄窗及水平分带 | 22 米 |
| 77986 | A01 主教学楼 | 南侧侧翼窄窗、上部窗带和红褐色陶板分缝 | 27 米 |
| 77955 | D03 化学实验楼 | 南侧及西端竖窗、水平分隔，南侧白色外露管道 | 19 米 |

高度、窗距、竖片、陶板分缝与管道尺寸均为照片比例估算；窄窗分布和管道折弯只表达可见特征，不是逐项测绘。其他 46 段建筑采用未测高度 18 米的中性轮廓实体，无通用窗格，不代表实际楼高。程序生成材质表现自然表面，不直接使用原始照片作纹理。

## 未制作范围

无室内、家具、房间、楼梯或可进入建筑。A01 照片显示中庭开敞，但没有完整平面支持，当前保留闭合轮廓，不制作中庭与入口通道；这一区域与实景存在明显差异。图书馆坡道、门洞和水景没有有效几何，未制作。B02 彩虹长廊仅保留来源节点，不把架空结构做成实心墙，也不据局部照片补整条楼梯和梁柱。

未核实的建筑侧面、植被分布、场地内部划线、校门立体构造和地形不补画。照片为源站历史资料，不能证明当前现状。此版本是官方布局基础上的可行走初版，其中三栋有局部照片参考外观，不是照片级复刻。

## 再生成与接入

在仓库根目录运行 `python3 apps/game/tools/prepare_panjin.py`，再运行 `godot --headless --path apps/game --script tools/build_panjin.gd` 和 `godot --headless --path apps/game --script tools/server_export/build_worlds.gd`。工具从自身位置解析路径，只读取已归档资料，不在导出期间联网。

盘锦出生点为局部 (12,0.35,-62)，位于主教学楼南侧外部。小地图与大地图自动读取注册表中的盘锦 manifest，传送沿用原有场景切换。客户端与游戏服应共同发布新模型、边界、碰撞和出生点。数据库、API、协议、依赖、环境变量及 migration 变化：无。
