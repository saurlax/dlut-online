# 前端与像素世界

## 当前入口

Next.js 以 SSG 模式生成产品入口、`/campus/` 校园地图和静态 404 页面。页面语言为简体中文，保留字体默认字间距，不引入外部字体请求。首页通过“进入校园”打开地图；首页与游戏之间使用原生链接做整页切换，不依赖静态服务器上的 RSC 分段预取重写。

界面使用本地托管的缝合像素字体，选择 12px 简体中文比例版。所有可见文字，包括按钮、设置标题、错误和来源署名，使用同一原生字号，不使用合成粗体或斜体，保留默认字距。文字先在 12px 画布中以基线 10 栅格化，alpha 规整为 0 或 255，再随界面整数放大；DOM 保留原文供读屏与按钮名称读取。字库及 OFL 授权文件随静态资源发布，字体来源记录在 `CREDITS.md`。

## 显示像素网格

`game/pixel-grid.ts` 统一计算显示单位。设浏览器 `devicePixelRatio` 为 d，一个原生像素占 `q = max(1, round(2 × d))` 个物理像素，对应 `q / d` 个 CSS 像素。DPR 为 1、1.25、1.5、2、3 时，q 分别为 2、3、3、4、6。这里保证像素格占整数个屏幕像素，不承诺不同显示器上的毫米尺寸相同。

瓦片、建筑、植被、16×16 图标、12px 字体、按钮边框、高光、阴影、焦点框、间距、加载条和首页图像都服从此网格。地图保持原生分辨率渲染，界面按一个原生像素等于一个布局像素排版，再以共享倍率从左上角映射到屏幕。弹窗宽高和居中位置对齐整数网格，不直接给 CSS 边框设置小数宽度；按钮按压只移动一个完整原生像素，不使用连续位移动画。

窗口和全屏尺寸变化只改变可见范围；DPR 变化时重新计算共享倍率并更新画布及界面，包括移动到不同缩放率的显示器。最右和最下不足一格的区域裁切，不拉伸最后一格。Phaser 的相机倍率为 1，画布最近邻放大，不叠加第二次相机缩放。

界面通过名称、层级和布局传达用途，不默认配套说明段落、副标题或提示卡。`description` 等说明组件仅用于用户操作和决策必需的信息；具体文案约定见 [开发约定](../DEVELOPMENT.md#界面与文案)。

按钮与链接复用 `components/game-button.tsx` 和同目录样式，使用大工蓝、书页白、禾苗绿色与少量暖金点缀。主操作配书籍托起幼苗的像素徽记，设置和次操作使用统一的像素图标、边框、高光及按压层次。交互复杂度由按需引入的 Radix Primitives 承担，现有设置使用 Dialog；视觉由项目样式控制，不引入整套通用视觉主题。

首页采用游戏标题画面：蓝色 DLUT Online 标志结合书籍与幼苗意象，背景为沿主楼中轴线正视主楼与毛泽东像的横向像素插画。标题放在上方天空，入口放在前景，保持地标可见，不添加介绍卡片或尚不可用的菜单入口。窄屏裁切同一横向插画，横屏低高度时入口移到右下方。

标题插画使用 imagegen 生成，再通过 `tools/prepare_title_assets.py` 最近邻采样并规整调色板。正式背景为 512×288、最多 64 色，透明标志为 320×160、最多 40 种可见颜色且 alpha 仅取 0 或 255。浏览器先将背景裁切和标志的自适应尺寸以最近邻采样到共享网格的原生画布，再按统一倍率显示，不使用 CSS cover 或任意尺寸图片直接缩放；不加载生成时的大图或实景照片。来源、提示词与像素处理约定记录在 `references/branding/title-screen.json`。首页插画独立于地理网格，不作为地图几何依据。

## 校园地图

Phaser 负责俯视二维像素世界，使用 WebGL 绘制；React 管理页面、表单、菜单和游戏实例挂载，不驱动逐帧模拟。游戏模块仅在浏览器按需加载，离开游戏时销毁实例和监听器。

开发区校区地图固定北朝上，以 WGS84 资料生成 1 米地面格。地面和植被模块使用原生 16×16 PNG，湖岸和步道保留斜向连接及朝向一致的岸坡。建筑为独立透明整图，画布边长为 16 的整数倍，像素密度与地面一致，落地点、占地和前后遮挡仍由真实网格决定；建筑不强拆成一米重复立面块。七舍的 DUT 标识面在当前视角不可见，不绘制、不旋转楼体展示它。来源与误差见[地图生成](map-generation.md)。

主画面使用上述共享显示倍率，以涌泉湖北岸的登记焦点为中心，不支持拖拽平移、滚轮缩放或全图切换。每个 1 米瓦片保留 16×16 原始像素，显示边长为 16q 个物理像素；建筑与植被使用相同像素密度。窗口尺寸与全屏状态变化时保持中心不变，按 64×64 米分块创建多层瓦片和植被，离开视野后释放。

游戏 HUD 仅保留右上方的设置齿轮，不展示小地图。右下方 OSM 署名保留为不可点击的纯文字，不接受指针事件。

点击齿轮或按 Escape 打开设置，设置提供进入或退出全屏、返回标题和继续游戏。弹窗使用 Radix Dialog 管理模态交互、焦点限制、关闭后的焦点恢复及 Escape 关闭，点击遮罩或继续游戏也可关闭。弹窗只提供标题，不添加重复说明文字。全屏请求失败时在设置中显示反馈，不添加无实际功能的音量或画质选项。

加载时显示底部进度条，不叠加技术说明、地区介绍或调试文本。加载失败显示错误；地图尚无人物移动、碰撞和联机会话。

## 后续游戏交互

优先建设有参考资料支持的小范围校园。采用统一像素网格、角色比例和遮挡规则，地面碰撞与装饰分离。昼夜、局部光晕、天气粒子和着色器服务于校园氛围；实时遮挡阴影在明确需求与性能验证后引入。

移动、朝向、失焦停止、暂停与恢复需同时考虑键盘和触屏。客户端预测与插值不改变后端权威状态；断线时停止发送移动，并明确显示连接状态。

## 边界

当前提供固定校园视图与设置、简化建筑外观和有来源的植被分布，不包含室内、角色、账号界面或 WebRTC 游戏同步。Next.js 不提供服务端 API 或实时游戏模拟。
