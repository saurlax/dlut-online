## Why

Web 默认进入凌水占位场景，却必须先下载约 51 MB 的开发区资源。按校区独立打包并在首次传送时下载，可以减少首屏等待，同时保留完整校园的渲染与碰撞。

## What Changes

- Web 首包保留默认凌水校区与共享资源，开发区和盘锦使用独立校区包。
- 首次传送按需下载校区包，展示原生进度和失败重试，成功后再切换场景；同一会话复用已加载包。
- 桌面仍离线包含全部校区，编辑器和校园内部结构不变，不进行网格切分。

## Capabilities

### New Capabilities

- `campus-resource-packs`: Web 校区资源包的导出、按需下载和可靠传送。

### Modified Capabilities

无。

## Impact

客户端原生导出插件、校区加载器、地图传送界面、相关回归测试与文档。Go 静态服务继续托管 /web/；不新增游戏联网功能或依赖，不改变建筑与室内范围。
