# 前端与像素世界

## 当前入口

Next.js 以 SSG 模式生成产品入口、`/campus/` 校园地图和静态 404 页面。页面语言为简体中文，保留字体默认字间距，不引入外部字体请求。首页通过“进入校园”打开地图；首页与游戏之间使用原生链接做整页切换，不依赖静态服务器上的 RSC 分段预取重写。

界面使用本地托管的缝合像素字体，选择 12px 简体中文比例版。正文与按钮以 24px 显示，小号来源署名使用 12px；不使用合成粗体或斜体，保留默认字距。字库及 OFL 授权文件随静态资源发布，字体来源记录在 `CREDITS.md`。

界面通过名称、层级和布局传达用途，不默认配套说明段落、副标题或提示卡。`description` 等说明组件仅用于用户操作和决策必需的信息；具体文案约定见 [开发约定](../DEVELOPMENT.md#界面与文案)。

首页采用游戏标题画面：蓝色 DLUT Online 标志结合书籍与幼苗意象，背景为沿主楼中轴线正视主楼与毛泽东像的横向像素插画。标题放在上方天空，入口放在前景，保持地标可见，不添加介绍卡片或尚不可用的菜单入口。窄屏裁切同一横向插画，横屏低高度时入口移到右下方。

标题插画使用 imagegen 生成，再通过 `tools/prepare_title_assets.py` 最近邻采样并规整调色板。正式背景为 512×288、最多 64 色，透明标志为 320×160、最多 40 种可见颜色且 alpha 仅取 0 或 255。浏览器使用最近邻像素显示；不加载生成时的大图或实景照片。来源、提示词与像素处理约定记录在 `references/branding/title-screen.json`。首页插画独立于地理网格，不作为地图几何依据。

## 校园地图

Phaser 负责俯视二维像素世界，使用 WebGL 绘制；React 管理页面、表单、菜单和游戏实例挂载，不驱动逐帧模拟。游戏模块仅在浏览器按需加载，离开游戏时销毁实例和监听器。

开发区校区地图固定北朝上，以 WGS84 资料生成 1 米地面格。地面和植被模块使用原生 16×16 PNG，湖岸和步道保留斜向连接及朝向一致的岸坡。建筑为独立透明整图，画布边长为 16 的整数倍，像素密度与地面一致，落地点、占地和前后遮挡仍由真实网格决定；建筑不强拆成一米重复立面块。七舍的 DUT 标识面在当前视角不可见，不绘制、不旋转楼体展示它。来源与误差见[地图生成](map-generation.md)。

主画面固定为两倍整数像素倍率，以涌泉湖北岸的登记焦点为中心，不支持拖拽平移、滚轮缩放或全图切换。窗口尺寸与全屏状态变化时，保持倍率和中心不变，只改变可见范围。按 64×64 米分块创建多层瓦片和植被，离开视野后释放。

游戏 HUD 位于右上方，包含北朝上的校园小地图及设置齿轮。小地图从相同材质格与建筑占地绘制，以方框表示当前相机视野，不伪造玩家位置。小地图不响应拖拽、缩放和点击传送。右下方 OSM 署名保留为不可点击的纯文字，不接受指针事件。

点击齿轮或按 Escape 打开设置，设置提供小地图显示开关、进入或退出全屏、返回标题和继续游戏。小地图开关保存在本机浏览器；弹窗使用原生 dialog 管理焦点与 Escape 关闭，点击遮罩或继续游戏也可关闭。全屏请求失败时在设置中显示反馈，不添加无实际功能的音量或画质选项。

加载时显示底部进度条，不叠加技术说明、地区介绍或调试文本。加载失败显示错误；地图尚无人物移动、碰撞和联机会话。

## 后续游戏交互

优先建设有参考资料支持的小范围校园。采用统一像素网格、角色比例和遮挡规则，地面碰撞与装饰分离。昼夜、局部光晕、天气粒子和着色器服务于校园氛围；实时遮挡阴影在明确需求与性能验证后引入。

移动、朝向、失焦停止、暂停与恢复需同时考虑键盘和触屏。客户端预测与插值不改变后端权威状态；断线时停止发送移动，并明确显示连接状态。

## 边界

当前提供固定校园视图、小地图与设置、简化建筑外观和有来源的植被分布，不包含室内、角色、账号界面或 WebRTC 游戏同步。Next.js 不提供服务端 API 或实时游戏模拟。
