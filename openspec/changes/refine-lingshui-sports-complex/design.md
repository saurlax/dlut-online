## Decisions

- 总轮廓与 Feature ID 保持不变。体育场内部曲线拟合与建筑分体记录在来源 JSON，所有尺度为照片比例估计，不声称标准400米场地或实测楼高。
- 体育场生成器与建筑生成器分开。跑道、草地和划线裁切到官方多边形，按材质合并；单独保留每个 Feature 节点。
- 主馆采用裁切到来源环的双叶曲面，游泳馆采用较低弧面。屋面及封闭外壳有结构碰撞；窗格、屋面细缝和座位装饰无碰撞。
- 西侧看台结构依据照片制作，阶梯结构使用碰撞标记，服务端从同一场景重新生成碰撞世界，不维护另一套手工模型。
- 不生成未核实外梯、入口通道、室内、全场围栏或周边树木。原始照片只离线使用；游戏无新增说明文本。

## Validation

保持原有313段轮廓、282个ID、314个三角化环。检查新增运动场结构与馆体的物理阻挡、装饰无碰撞、场地内部网格不越界。运行桌面/服务器导出和原生Forward+多视点渲染检查；不执行Web游戏验收。
