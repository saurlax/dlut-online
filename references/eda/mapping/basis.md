# 开发区校区建模依据

当前平面底稿采用 OSM，按 [三校区统一坐标基准](../../shared/mapping/osm-world-frame.json) 转换为局部 X 向东、Z 向南坐标。官网地图和照片用于身份核对与有依据的局部修正；可信优先级为照片 > 官网俯视图 > OSM，不能把屋檐或透视外包络当作墙脚。2026-09-09读取的官网资料作为历史档案保留。

## 可核对的数据

- `../../shared/mapping/campuses.json`：`/openmap/mapi/campus/v1` 的公开返回。开发区校区 ID 77298，中心为 (121.816326506145, 39.084522240291)。
- `bounds.json`：`/openmap/mapi/bd/v1/bound` 中筛选到开发区的 27 个轮廓。源站全部 550 条记录按每个点位于经度 121.80–121.83、纬度 39.07–39.10 筛选，不含其他校区。
- `tiles/`：官方二维底图 `/map?lyrs=lm30&x={x}&y={y}&z=16` 的历史参考瓦片，曾用于人工描摹道路中心线；瓦片不包含在客户端成品中，旧描线不作为当前道路基准。
- `osm-world.osm.gz` 与 `osm-world-source.json`：2026-09-16读取的 OSM 原始对象及摘要，保留 ID、版本、节点和时间戳。当前道路采用 OSM 中心线，宽度缺少来源时仍为类别估计。
- `ground-surfaces.json`：综合楼南广场和北院铺装分别描绘，以版本化 OSM 环线及楼边配准；保留中央绿岛，不把北侧院内照片用于南侧材质判断。南侧历史铺装的时效限制见下节。

## 精度边界

统一使用 WGS84 与同一校区原点，不再沿用旧官网质心平移。官网名称保留对应 Feature ID，OSM 匹配保留对象 ID 和版本；身份匹配并不证明墙脚准确，未解决的冲突不自动平均。

原始官网轮廓没有建筑楼高、楼层或地形高程。照片与模型估计见 [建筑依据](../buildings/basis.md)。地形平面要素使用 OSM；连续高程仍来自有来源的 Copernicus DSM，不能称为 OSM 高程或实测裸地。俯视图局部拟合误差不是实测精度，宽度、楼高及遮挡部位仍有不确定性。

本模型是公开地图覆盖范围的初版模型，其中信息楼、图书馆及1—5舍已按官方照片修正部分立面，七舍按官方63.6米高度和施工照片拆分高层与裙房，不代表全部现状建筑，也不是官方发布的三维模型。二期用地保留地图标注的地面区域，未凭空添加未核实建筑。

## 更新

### 2026-09-18 局部道路外景

`exterior-details.json` 登记环湖东侧OSM way/1076344082 v2顶点25至36之间约162米路段的黄色中心虚线、白色边线及五盏弯臂路灯。依据KFQ00下向航拍与已归档双湖照片的湖岸、图书馆和路口拓扑匹配，不是相机标定；线宽、灯高、灯具细部及沿道路的灯位均为视觉估计，不能称逐灯实测。路口斑马线尚未完成配准，未按任意桩号补建。

沥青采用世界尺度细颗粒材质，远处衰减颗粒以避免闪烁；不是对每处磨损的复刻。静态道线按DSM地形三角形裁切，位于路面上8毫米。灯杆仅采用半径0.085米简单圆柱碰撞，不为灯头、底座螺栓增加细碎碰撞。开发区既有道路向下绕序同时纠正；共享贴地生成器已修正，其余校区保存的模型本轮不重建。

五盏路灯与天空共用 `campus_environment.gd` 的太阳高度和单人/多人时间来源，每0.25秒更新；太阳方向Y值从0.02降至-0.06时渐亮，反向渐灭，暂停的大地图调时也生效。每盏灯保存一个向下略朝道路倾斜的聚光灯，范围16米、半角62度；灯罩自发光同步切换，白天关闭实际光源。阴影从40米起渐隐，灯光从100米起渐隐，渐隐长度25米。色温观感、强度和范围为夜间可读性设置，不代表现场灯具的实测配光或照度；不增加路灯数量，不改变碰撞。

生成入口为 `godot --headless --path apps/game --script tools/build_eda_exterior.gd`，静态细节场景挂在 `scenes/campuses/eda.tscn`；灯杆变更后执行既有服务端碰撞生成器。共享树干绕序修复使用 `tools/rebuild_vegetation_meshes.gd` 重建现有近远景资源，不改变种植数据与实例缓冲。

学苑桥审查见 `xueyuan-bridge-review.json`。2026年修缮近照确认青蓝顶棚、弧形骨架、水平栏杆、金属桥面及5厘米防滑条，但不能给出绝对标高、完整桥头台阶与支撑坐标；OSM way/309375782 v7仅作中心线底稿，layer=2不代表2米。本轮保留未完成状态，不以任意拱高或地形插值代替桥梁配准。

修改原始来源数据或 `apps/game/tools/prepare_campus.py` 中的高度估计，然后在仓库根目录依次执行 `python3 apps/game/tools/prepare_campus.py`和 `godot --headless --path apps/game --script tools/build_model.gd`，最后运行 `godot --headless --path apps/game --script tools/server_export/build_worlds.gd` 更新服务端碰撞。精细建筑可以以相同 Feature ID 替换，保持 Feature ID 和空间坐标一致。
