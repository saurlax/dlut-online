## Context

旧模型将所有树冠烘焙成一个 Mesh，树干按材质合并。植被位置为既有示意分布，不能当作实景测绘数据。

## Goals / Non-Goals

目标是复用几何、独立维护分布并缩小裁剪粒度，编辑器可直接查看。非目标是重做校园地形、补充无依据种植、修改碰撞或保证未经测量的帧率提升。

## Decisions

- 用独立 JSON 保存原有位置、高度和确定的变体/旋转，不再依赖生成建筑时的随机数消费顺序。
- 四份外部 ArrayMesh，各有树干和叶片两个表面；保留原有枝叶构造，统一缩放会改变个别枝叶的大小与排列。
- MultiMesh 按 64 米空间块与树型分组，使用完整变换后网格包围盒。负坐标使用 floor，不截断到零。
- 采用 ImporterMesh 生成原生 LOD；不引入透明树冠广告牌或运行时距离管理器。
- 植被场景作为校园场景的独立子场景，建筑模型不包含植被，服务器既有碰撞来源不变。
- 树模型资源通过 LFS 管理，桌面导出通过静态资源依赖收集；不新增框架或插件。

## Risks / Trade-offs

分块比原先两份校园级网格增加绘制批次，但改善资源复用和局部裁剪。离散叶片 LOD 简化有限。64 米与四变体是初始参数，需要实测，不声称最优；本轮不增加远景广告牌。现有植被仍是示意分布。

## Migration Plan

一次性沿用旧生成器随机序列提取分布，提交 JSON 作为后续权威输入。重新生成开发区模型、树资源与植被场景，校验非植被网格和碰撞未变化，执行桌面/服务端导出及实际渲染检查。
