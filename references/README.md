# 参考资料目录规范

本目录保存 DLUT Online 使用的外部资料、来源索引与可追溯的建模依据。校区资料先按校区归档，再按内容分类；共享资料单独存放。来源与许可统一登记在根目录 [CREDITS.md](../CREDITS.md)。

## 目录结构

```text
references/
├── README.md
├── shared/                 # 跨校区的数据、服务与通用参考
│   ├── mapping/            # 校区目录、官方地图坐标处理依据
│   ├── imagery/            # 跨校区全景站配置
│   └── weather.md          # 天气查询和太阳位置的来源、精度约定
├── lingshui/               # 凌水主校区
├── eda/                    # 开发区校区
└── panjin/                 # 盘锦校区
```

三个校区采用相同分类规则，按实际资料创建子目录，不复制其他校区的数据填空：

| 目录 | 内容与边界 |
|---|---|
| `mapping/` | 官方平面轮廓、红线、道路与场地布局、二维底图、坐标基准及筛选记录；二维轮廓不等于实测高程 |
| `terrain/` | DEM/DTM、等高线、高程点、坡度和地形来源索引 |
| `vegetation/` | 树木点位、树种、树高、冠幅及植被调查依据 |
| `buildings/` | 建筑详情、体量与立面配准参数、建筑平面及精度说明；`photos/` 保存照片和原接口索引，专题可按对象单独建目录 |
| `facilities/` | 运动场、广场及其他室外设施的专门测量或配准数据 |
| `imagery/` | 跨对象影像；`panoramas/` 保存全景及配置，`satellite/` 保存卫星影像与配准索引；专题只引用，不重复保存原图 |
| `events/` | 活动公告、日程和规则来源；有真实资料时创建，资料归档不代表游戏已实现活动 |
| `documents/` | 无法归入以上主题的校区文件、制度、历史资料等；建筑图纸仍归 `buildings/`，避免所有文件堆进此处 |

涉及多个校区的资料按同样主题放在 `shared/`；单校区资料不放共享区。无资料的分类可以暂不创建，已有分类 README 中的“未收录”也不等于存在测绘数据。

## 文件命名与录入

- 校区 ID 固定为 `lingshui`、`eda`、`panjin`，路径使用英文。已有官方 Feature ID、影像 ID 和原索引保持不变。
- 一个来源记录至少包含：来源名称（与 CREDITS 对应）、发布者、原始 URL、对象/瓦片 ID、覆盖范围、读取日期、用途、许可名称和条款 URL、授权状态。
- 测绘资料另记采集日期、水平坐标系、垂直基准、单位、采样间距、精度与缺测范围。未知项明确写“未核实”，不把照片比例估计写成实测。
- 图片等二进制资料记录原文件名和 SHA-256；已有 JSON 索引继续沿用，不为统一格式破坏原响应。新来源用同目录 `source.json` 或 `<对象ID>.json` 作旁侧记录。
- 原始响应与人工解释分开：原接口索引保留源数据，配准参数、估计值及适用边界放专题 JSON 或 `basis.md`。原文 URL 不因本地迁移而改写。
- 新记录中的本地路径统一写仓库相对路径。现有记录允许沿用文件相对路径；`facades.json` 的裸照片名默认在同级 `photos/` 下查找。移动时同步生成器、文档和记录内路径。
- 候选、已用于离线参考、已用于生成资源、随产品分发必须区分。公开可访问不等于有第三方复制或再分发许可；许可不明写明待确认。

## 文档职责

- `README.md` 只说明目录职责、命名、录入方式和索引，不记录逐轮验收、完成百分比或发布结果。
- `basis.md` 保存长期需要的来源解释、配准、估计参数和适用边界。逐对象事实优先维护在 JSON；后续更新现有主题，不按每次迭代新增报告。
- 需求、实现范围和任务状态维护在 `openspec/`。截图、日志、一次性核验脚本放忽略的 `.local/`，长期文档不得以它们作为唯一依据。
- [CREDITS.md](../CREDITS.md) 是项目第三方版权与许可声明；声明只维护根目录这一份，桌面导出自动复制到资源包，macOS 打包同时放入 DMG；字体等第三方许可原文继续保留在对应应用内。

## 原始资料与运行资源

参考原图默认不进入 Godot 客户端，运行数据和模型放 `apps/game/assets/campuses/<campus_id>/`。网站实际展示的照片、视频属于分发资源，必须单独登记其用途与许可。程序生成的树木分布不是外部调查资料，不移入本目录冒充测绘成果。

图片等二进制文件继续遵循根目录 `.gitattributes` 的 Git LFS 规则；LFS 指针不是可查看原图。大型可重取数据不随意提交，先保留可复现下载地址、版本和校验值。资料路径改动应检查文件清单、引用及生成工具读取，不为目录整理重建校园模型。
