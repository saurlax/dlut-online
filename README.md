# DLUT Online

在像素校园里相遇。

DLUT Online 是以大连理工大学为主题的浏览器多人在线游戏。我们希望用俯视像素画呈现校园中的道路、建筑与日常风景，让不同地方的同学可以走进同一个校园世界。

## 我们想做的校园

- 打开网页即可进入，面向电脑和移动设备。
- 以真实校园资料为依据，用统一的像素美术重新表达校园。
- 与其他玩家一起行走、相遇，感受昼夜和天气带来的氛围变化。
- 保持轻松、干净的探索体验，让校园本身成为主角。

## 项目状态

项目处于基础工程初始化阶段，当前提供网页入口和账号后端基础。可探索的校园、正式美术、光照与多人游戏尚未实现。
