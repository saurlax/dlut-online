保存本校区树木点位、树种、树高、冠幅、覆盖范围与调查日期。来源图片可引用 [建筑照片](../buildings/photos/) 或本校区影像资料，不重复复制；新调查另记定位方法、精度和许可。

目前未归档本校区逐树测绘数据。程序化或估计分布属于运行资源及其生成参数，不是原始调查成果；不得复制其他校区点位补齐。
