# Go 服务

在此目录运行 `go run .`，默认读取 `../client/build/web`，监听 `127.0.0.1:8060`，游戏入口为 `/web/`。先运行客户端导出工具生成资源。

可通过 `-addr` 和 `-web-dir` 指定监听地址及资源目录；相对路径以工作目录为准。构建使用 `go build -o build/server .`，测试使用 `go test ./...`。

目前只提供 Godot 静态资源，首页、API 和 WebSocket 尚未实现，对应路径返回 404。资源使用重新验证缓存策略，缺失文件返回 404，不回退到首页。不将游戏资源嵌入 Go 二进制。
