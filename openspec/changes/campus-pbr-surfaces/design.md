## Context
沿用现有 4 列 8 行、重复 0.4 米的面砖颜色图和已登记局部；不从颜色亮暗推断高度。共享表面生成器的 map_box 原先将所有侧面投影至 XY，薄边 UV 退化，且未同步更新切线。

## Goals / Non-Goals
目标：改善已有面砖与石铺地近景受光；保留静态可编辑场景和碰撞。非目标：新增建筑细部、室内、天气功能、全校材质替换或修改画质预设。

## Decisions
- 离线 GDScript 按原网格生成 1024 像素法向和粗糙度数据图。凹凸仅模拟浅填缝过渡，釉面与填缝分开设置粗糙度；不是照片反演的深度。
- 立面米制 UV 不变，薄侧边选择非退化平面，再由 SurfaceTool 重算切线。
- 石铺地保留已有颜色、砖缝方向和尺度，用视空间表面梯度扰动法线，适配随地形变形的网格；无顶点位移。其他铺地默认关闭新效果。
- 远处亚像素颗粒向平均值收敛，减少行走时闪烁。无新增运行依赖。

## Risks / Trade-offs
生成数据图的规则网格与旧生成颜色图并非扫描级逐像素配准；只适用于当前面砖。强度保持克制并通过近远景检查。Mobile 着色兼容性另行检查，不能用桌面性能代替真机性能。
