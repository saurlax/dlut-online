# 前端与像素世界

## 当前入口

大地图统一显示大连全域概览和三校区细节；校区定位仅调整地图视野，不改变角色位置或连接，选中地标并点击“快速前往”才进入目标校区并落在该地标附近。三个校区作为同一游戏内的独立区域，保持各自地理坐标，按当前区域加载场景资源。同校区传送复用现有连接；跨校区仅在当前 React 页面内替换场景和实时连接，不重新加载网页，角色会话保持有效。地址固定为 `/game/`，校区与目标地标通过连接首条认证消息传递。服务端校验目标地标后发送初始位置，首次成功后消费传送目标，重连不重复传送。首次进入或刷新页面时进入凌水主校区，在主楼附近可通行区域随机出生。地面、模型、水面动画、地图图像和地标加载对应校区资源，大地图与小地图保留建筑院落内孔。

Vite 构建产品入口、`/game/` 游戏页面和静态 404 页的独立 HTML，React 在浏览器挂载界面。页面语言为简体中文，保留字体默认字间距，不引入外部字体请求。首页未登录显示“登录”，登录成功后显示“进入校园”，点击后准备角色再打开地图；游戏入口检查已准备的会话和令牌有效期，无有效会话时返回首页。首页与游戏之间使用原生链接做整页切换。游戏页面根据地图数据和 Three.js 资源加载进度显示进度条，场景准备完成后显示游戏界面。

游戏时间使用服务器校准的北京时间，白天与夜晚根据实际时间变化。三个校区的天气分别按对应坐标从 Open-Meteo 获取，服务端每 15 分钟同步真实时间和天气并广播，客户端显示雨、雪或雾效果；同步失败时保留上次天气。管理员可临时使用指令调整所在校区的时间或天气，下一次成功同步天气时恢复真实天气，每次同步均恢复真实时间。保留的 HTTP 天气和指令接口仍对应开发区。

未登录时首页登录弹窗提供游客进入。游客使用服务端签发的临时会话和“游客”加六位数字的名字，穿预设服装，可移动和聊天，不能修改装备或背包；不创建用户和角色记录。游客会话保存在当前标签页，12 小时后失效，服务器重启后需重新进入。

触屏设备在游戏左下方显示像素摇杆，拖动控制角色移动方向和速度；松手、触摸取消、失焦或打开弹窗时停止。摇杆使用现有碰撞与镜头逻辑，聊天区域在触屏设备上移以留出操作空间，左下角聊天按钮打开或关闭聊天输入框。

F 为通用场景交互键。距玩家 2.75 米内有可用且地面相通的操作时，底部横条显示最近操作的名称。按 F 或点击横条触发同一操作；输入文字、打开弹窗或游戏失焦时隐藏横条并暂停交互。横条随校区界面预先渲染，显隐只更新可见性。

触屏背包支持点击物品后点击目标格，也支持拖动到目标格；拿起的物品显示在角色预览旁，松到无效位置时取消拖动。游客的背包与装备保持只读。

界面使用本地托管的缝合像素字体，选择 12px 简体中文比例版。所有可见文字，包括按钮、设置标题、错误和来源署名，使用同一原生字号，不使用合成粗体或斜体，保留默认字距。文字先在 12px 画布中以基线 10 栅格化，alpha 规整为 0 或 255，再随用户选择的界面倍率显示；DOM 保留原文供读屏与按钮名称读取。字库及 OFL 授权文件随静态资源发布，字体来源记录在 `CREDITS.md`。

## 显示像素网格

地图与界面使用独立的显示倍率，保留原生素材与最近邻采样，不要求二者的显示像素颗粒一致，不操作浏览器缩放。

地图与首页背景由 `game/pixel-grid.ts` 沿用原有显示规则：设浏览器 `devicePixelRatio` 为 d，一个原生像素占 `q = max(1, round(2 × d))` 个设备像素，对应 `q / d` 个 CSS 像素。DPR 不是显示器真实 PPI，不能仅凭 DPR 推导物理毫米。窗口和全屏尺寸变化时重算世界可见范围，DPR 变化时只重算世界画布倍率；Three.js 以原生画布分辨率渲染并最近邻放大；正交相机每米对应 12 个画布像素，原生材质保持 16 像素/米，以最近邻采样。首页背景沿用原有显示比例。

界面由 `game/interface-scale.ts` 独立计算：小、标准、大分别以 1、1.5、2 CSS 像素显示一个原生界面像素，默认标准（1.5×）。界面倍率不按 DPR 取整；逻辑界面视口为 `floor(window.innerWidth / scale)` × `floor(window.innerHeight / scale)`。设置中的“界面尺寸”即时切换，保存至本浏览器当前源的 `localStorage`（`do-interface-scale`），刷新及回到首页继续使用，其他同源标签页同步更新。

按钮、字体、图标、物品格、小地图、地图弹窗、账号与设置弹窗沿用所选界面倍率；实际校园瓦片、建筑、植被、人物、镜头和首页背景不受界面尺寸改变影响。首页 Logo 仍固定为 320×160 CSS 像素。界面按原生像素布局，弹窗与视口边界按界面逻辑坐标计算；窄屏的大尺寸界面允许背包窗口内的物品格横向滚动。按钮按压移动一个原生界面像素。所有界面禁用浏览器默认及自定义 outline，鼠标点击、Tab 和方向键聚焦不显示外部强调框；保留按钮按压、选中底色与物品格选中状态。

界面通过名称、层级和布局传达用途，不默认配套说明段落、副标题或提示卡。`description` 等说明组件仅用于用户操作和决策必需的信息；具体文案约定见 [开发约定](../DEVELOPMENT.md#界面与文案)。

按钮与链接复用 `components/game-button.tsx` 和同目录样式，使用大工蓝与书页白。按钮及窗口的外轮廓为一原生像素，按钮仅保留一像素高光、下沿阴影和按压位移，不叠加第二层内框、铆钉或厚色带。像素格对齐与线条重量分别核对，不能以同网格为由默认两像素描边与地图一像素细线具有相同颗粒感。文字按钮默认不配图标，文字居中且不保留图标占位；设置入口保留简化的线框齿轮，弹窗标题只显示文字。书籍与禾苗意象保留在固定 Logo 中。交互复杂度由按需引入的 Radix Primitives 承担，设置与关于使用 Dialog 并共享 `components/game-dialog.css`；视觉由项目样式控制，不引入整套通用视觉主题。

首页采用游戏标题画面：蓝色 DLUT Online 标志结合书籍与幼苗意象，背景为沿主楼中轴线正视主楼与毛泽东像的横向像素插画。标题放在上方天空，前景纵向放置“进入校园”和“关于”，保持地标可见，不添加介绍卡片或尚不可用的菜单入口。窄屏裁切同一横向插画，横屏低高度时按钮移到右下方。

“关于”集中展示 OpenStreetMap 数据署名及 ODbL 许可、缝合像素字体及 OFL、项目美术与实景和风格参考、Radix、Three.js 及 MIT 许可，来源与 `CREDITS.md` 保持一致，提供可访问的来源和许可链接。弹窗沿用像素字体及界面显示网格，长内容可滚动，滚动位置对齐原生像素，标题栏右上角提供 X 关闭按钮；支持 Escape、点击遮罩关闭和焦点恢复。界面按逻辑视口收紧窄屏和低高度布局，长版权文字在原生画布内换行，保持相同字形网格与原始可访问名称。校园行走画面不叠加版权署名；全屏大地图另提供数据来源链接。

标题插画使用 imagegen 生成，再通过 `tools/prepare_title_assets.py` 最近邻采样并规整调色板。正式背景为 512×288、最多 64 色，透明标志为 320×160、最多 40 种可见颜色且 alpha 仅取 0 或 255。标志直接作为固定 320×160 CSS 像素的图片居中显示，不放进背景画布、不在窗口变化时重新采样或放大。背景单独以最近邻采样到世界网格的原生画布，再按世界倍率显示；不加载生成时的大图或实景照片。来源、提示词与像素处理约定记录在 `references/branding/title-screen.json`。首页插画独立于地理网格，不作为地图几何依据。

账号、角色创建、背包、设置和关于弹窗统一使用固定 286 原生像素宽度，窄屏时只按视口可用宽度收紧，取偶数原生像素保证居中对齐，不根据标题、地标名称或正文长度改变宽度。地图另使用全屏界面。标题栏右上角统一使用 X 关闭按钮，长内容滚动时标题栏保留可见；不再使用底部返回或继续游戏按钮关闭弹窗，设置中的“返回标题”仍作为页面导航。

## 校园地图

Three.js 负责 HD-2D 校园场景，以 WebGL2 绘制立体建筑、像素地面及透明人物和植被；React 管理页面、表单、菜单和游戏实例挂载，不驱动逐帧模拟。游戏模块仅在浏览器按需加载，离开游戏时销毁动画、监听器、几何体、材质、贴图及后处理资源。

校园动物是无碰撞的场景实体。原生像素贴图随镜头显示，有公开名字的个体沿用人物的名牌渲染层，随动物显示。凌水主校区的猫使用匿名编号，无头顶名牌。猫在楼外短路线行走，停下时轮换眨眼待机、蜷睡和舔爪。性格分为亲人、警惕和怕人。亲人猫会停下等待并提供「抚摸」，抚摸后眯眼并依次飘出三颗爱心；警惕和怕人的猫会在不同距离沿原路线退开。天鹅和鸭在凌水湖成群游动。开发区思源湖近岸有天鹅群，田径场和锦屏山有野猪群，书韵广场有大狗群。群体路线为整体提供移动方向。每只成员依据附近同伴的距离、方向和位置独立转向，过近时分开，偏离时靠拢，并避开不可通行地面或湖岸。野猪平时会在随机时机散开或重新聚拢，每次散开的方向、幅度和持续时间各有变化。野猪和大狗分别在 8 米和 9 米内发现视线畅通的玩家，头顶冒出红色生气图标并追逐。追击距离上限为 15 米，活动路线外围 18 米为领地边界。玩家脱离范围或离开校区时，追击停止，动物回到群体。野猪归队途中若仍在领地内，看到领地内的玩家可以再次发起追击。匿名成员可通过实体编号定位。算法参考 [Craig Reynolds 的 Boids](https://www.red3d.com/cwr/boids/)。路线以校区地图西北角为原点，X 向东、Z 向南，单位为米。Go 模拟动物的位置和行为，并同步给同校区玩家。动物资料和收录范围见[校园动物来源](../references/campus-animals.md)。

玩家和动物初始生命值均为 100，当前玩家的血量显示在小地图下方。野猪冲撞造成 22 点伤害，大狗扑咬造成 15 点伤害，命中前都有短暂蓄力，玩家可以走出攻击范围。命中时屏幕边缘短暂泛红，方向标指向命中时的攻击来源，同时命中可分别显示。生命值降至零时角色倒地并冒出白烟，其他玩家也能看到。死亡界面显示死因和复活倒计时，4 秒后在附近满血复活，并获得 4 秒保护，保护期间角色半透明闪烁，对附近玩家同步显示。聊天栏显示玩家名字和死因。

动物使用 `apps/web/public/sprites/animals/` 中以素材名或实体 ID 命名的透明 PNG，横向排列 20×16 像素的动作帧。猫依次为待机、步态一、步态二、眨眼、睡觉、呼吸、梳毛、舔爪、被抚摸。天鹅、鸭、野猪和大狗使用前三帧。同类个体可共享动作图。抚摸特效共用同目录的 `heart.png`。

开发区校区地图固定北朝上，以 WGS84 资料生成 1 米地面格，场景 X 向东、Y 向上、Z 向南。正交镜头从南侧斜俯视，不旋转校园。地面和植被继续使用原生 16×16 PNG，湖岸和步道保持既有地理连接。15 栋建筑使用依据旧版登记资料重建的简化底模和独立像素 UV 贴图，窗格、楼层线及细部颜色烘焙到贴图，不再使用密集装饰网格。图书馆保留圆厅、塔楼和高低连接翼，教学楼 C 区保留圆体与直翼；七舍保留原塔楼及裙房，不叠加二维建筑图。缺少立面资料的三轴实验室保持地面轮廓。建筑落点用旧模型 origin 与现有地图 offset 换算，不按楼栋单独移动或缩放。旧版地形高程暂未接入，楼体统一放到当前平面地面，不宣称完成地形迁移。来源与误差见[地图生成](map-generation.md)。

主画面未创建人物时以涌泉湖北岸的登记焦点为中心，创建后跟随人物。横纵方向的 40%–60% 为镜头静止区，越界后仅移动到人物回到区间边缘；镜头中心限制在地图范围内。窗口、DPR 和全屏变化时更新正交视锥与画布。有角色时重新居中。不支持拖拽平移或滚轮缩放，按 M 打开地图窗口。地面按 64×64 米区块在视野及阴影余量范围内合成原生贴图并创建网格，离开范围后释放，不生成或加载全校大贴图。建筑模型和各自 PNG 贴图在加载阶段最多并行解码两栋；贴图使用最近邻采样，不再覆盖成统一重复材质。植被按原型使用 InstancedMesh 合并绘制，共享材质和几何体，仅填入附近实例。

游戏 HUD 左上方显示圆形像素小地图，右上方显示设置按钮，右下角按“用户名 60FPS 25ms”格式显示角色名、帧率及游戏连接往返延迟（毫秒），每 500 毫秒刷新显示；FPS 来自实际游戏渲染循环的原始帧间隔，不使用移动积分的 50 毫秒截断值。延迟通过同一 WebSocket 每 2 秒测量，首次测量前或连接断开时显示“--ms”。不显示右下角来源标识。设置按钮使用缝合像素字体的 U+2699 齿轮字形，沿用 PixelText 原生栅格化，不使用系统彩色 emoji。底部 I 入口只提供背包。地图数据的署名及许可可从首页“关于”查看，地图全屏界面也保留来源链接。

点击齿轮或按 Escape 打开设置，设置提供小、标准、大三档界面尺寸、进入或退出全屏和返回标题。弹窗使用 Radix Dialog 管理模态交互、焦点限制、关闭后的焦点恢复及 Escape 关闭，点击遮罩或右上角 X 也可关闭。弹窗只提供标题，不添加重复说明文字。全屏请求失败时在设置中显示反馈，不添加无实际功能的音量或画质选项。

加载时显示底部进度条，不叠加技术说明、地区介绍或调试文本。加载失败显示错误。地图通过 WebSocket 同步附近玩家、外观、朝向与走路动画；其他玩家使用同一像素人物和名字渲染规则，离线后移除。步行 3 米/秒，Shift 跑步 6 米/秒，键盘和摇杆共用 Go 校验的碰撞与速度规则。客户端逐帧预测并按已确认输入校正自身位置，远端使用插值；具体协议见[多人通信](networking.md)。

## 后续游戏交互

优先建设有参考资料支持的小范围校园。采用统一像素网格、角色比例和遮挡规则，地面碰撞与装饰分离。昼夜、天气粒子和后处理服务于校园氛围。当前已接入太阳方向光、环境光和实时阴影，服务端时间与天气更新光照；阴影边缘采用 PCF 柔化，保留较浅的阴影与环境补光；高光偏暖、暗部偏冷，傍晚随太阳高度加强暖色。泛光和基于场景深度的景深不作用于 DOM 界面；焦点逐帧跟随人物，附近保持清晰，远近景逐渐虚化，并使用轻微暗角收束画面。阴影与遮挡判定按 150 毫秒更新，移动仍逐帧处理。

移动、朝向、失焦停止、暂停与恢复需同时考虑键盘和触屏。客户端预测与插值不改变后端权威状态；断线时停止发送移动，并明确显示连接状态。

## 边界

当前提供固定斜俯视的人物跟随视图、设置、既有 3D 建筑外观和有来源的植被分布，以及账号、角色创建和背包穿脱，不包含室内或 WebRTC 游戏同步。服务端 API 和实时通信由 Go 提供。

## 开发区室外设施

`site-fixtures.json` 登记 14 盏环湖弯臂路灯、C 区庭院和学苑桥西侧的 3 盏圆环灯，以及桥头 2 组各有两块并排面板的公告栏。数量、路段、朝向和尺寸来自旧版登记资料，位置保留估计性质，不按等间距扩展到全校。公告栏只表达框架和面板，不编造海报内容；未定位的长椅不摆放。

设施采用简化三维体块，随世界画布像素化显示。弯臂灯高约 6 米，圆环灯高约 3.6 米。灯具与校园共用服务器校准时间和太阳高度，日落附近渐亮、日出渐灭，灯罩自发光与暖色光晕同步变化。场景保持固定 4 个聚光灯，最多照亮镜头附近 4 盏灯的地面和物件，16 米照射范围、柔和边缘及强度为游戏美术设置；远处保留灯头亮点。聚光灯不额外产生阴影贴图，设施仍参与太阳阴影。

`game/site-fixtures.ts` 管理几何体、灯光和销毁。灯光选择每 200 毫秒更新，保持固定着色器光源数量。灯杆使用半径 0.14 米的简化圆形碰撞，公告栏使用有朝向的窄矩形碰撞；人物移动、初始落点和地图传送统一通过 `canStand` 检查脚底范围与设施，不改变原有地面材质和建筑占地。

## 全屏大地图

点击小地图或按 M 打开覆盖整个游戏视口的大地图，M、Escape 或右上角 X 关闭；不是网页跳转，不改变地址。模态打开期间停止人物移动；输入框中的 M 不触发地图，其他模态窗口打开时不叠加，关闭地图不会打开设置。大地图是固定 286 像素弹窗约定的例外。

MapLibre GL JS 6.16.0 在打开地图时按需加载，使用独立的本地 ESM worker。浏览器只请求本地静态图层，不连接在线底图或字体服务。每次打开时以玩家当前位置为中心，使用 17 级缩放显示附近地标；尚无玩家位置时展示全域概览。北朝上，禁止旋转；鼠标拖动、滚轮、触屏拖动和双指缩放均改变地图视野，右下角提供缩放按钮。右侧依次为凌水主校区、开发区校区、盘锦校区定位按钮，另有大连全域复位；这些按钮调用地图定位，不传送角色，也不切换游戏场景。界面继续使用像素字体和独立界面倍率。全屏地图打开时，界面倍率通过 CSS zoom 应用到布局，地图画布按界面倍率和设备像素比绘制，栅格采用最近邻采样。

初始显示包含大连全域并向北延伸至盘锦校区的区域概览，来源为归档的 Natural Earth 与 Mapzen 数据。校园层为按官方地图参考生成的三张完整 imagegen 插画，按主楼广场样片重绘，并由 Retro Diffusion Standard 保留原片分辨率、整理为每校区最多 48 色的像素图，采用最近邻显示，整张图中的建筑、道路及植被同步缩放，不再加载独立建筑图标。插画四角按已登记的人工选点做近似地理配准；当前为本地预览，主校区局部存在数十米偏移，校园轮廓之外透明，校内街道标签随缩放显示。地标点选、像素标签、当前位置和传送目标继续使用现有 WGS84 数据；图片内容不改变游戏地面与碰撞。放大后可点选 242 个已有建筑与设施部分，显示名称及“快速前往”。校园外仍为区域概览。来源、配准残差与生成规则见地图规范。

点击建筑或图标只选中并高亮，不立即传送。点击“快速前往”由 Go 依据登记地标 ID 在建筑南侧附近选择可通行落点；站位不是实测入口。同校区沿用当前连接，跨校区在当前页面内替换区域场景和连接；不整页重载、不向页面或 WebSocket URL 添加查询参数。初始位置或传送位置由服务端确认，不使用客户端自报坐标。

大地图标签统一通过 PixelText 原生栅格化。区域概览显示城市与校区名称；放大后显示归档 OSM 中的街道、湖泊、广场、周边区域与校园地点，以及已有建筑名称。13 级展开主要建筑、道路与校园区域，14 级展开其他建筑，16 级展开校门和雕塑等小地点；街道片区名称可在 12 级出现。标签按屏幕占地避让，并避开地图控件和建筑图；主要建筑优先，选中的地标名称优先。建筑标签可点选并显示“快速前往”，道路和区域标签只作标注。来源未登记的名称不补造。

## 实时小地图

左上角为原生 64×64 圆形像素画布，北朝上，每个缩略像素对应 2 米，显示人物周围约 128 米范围。底图从现有地面材质与真实建筑占地生成，不使用示意大地图美术；人物居中，并标记朝向。没有角色时显示登记焦点且不绘制玩家标记。位置以最多每秒 10 次检查，只有取整位置、朝向或角色存在状态改变时重绘；不通过 React 逐帧更新。人物移动、快速前往和退出账号均更新显示。圆形遮罩与边框在原生像素逐点生成，alpha 只取 0 或 255，跟随界面显示倍率。点击小地图打开已有地图窗口，其他模态窗口打开时不叠加。背包入口统一通过底部 I 按钮访问。

## 环境动画

地面与植被的原生瓦片按地图 textures 顺序读取 tile-atlas.png。前端将可见地面区块的原有图层依次在画布合成，再以 DataTexture 一次上传，保留最近邻采样；植被从原型 RLE 合成独立透明贴图，在原登记根部立起，并绕根部轻微风摆。水面使用 animations/manifest.json 的 PNG 图集和帧时长，由 GPU 在预加载图集中切换帧。区块地面只在创建时上传一次；不随水波重绘画布或重复上传整块地面。地面不透明贴图的 alpha 通道登记水面像素对应的图集行，岸坡、步道及其他覆盖保持静态，水面仍使用相同的光照、阴影和景深。不使用 GIF。地图数据仍整体读取，不因此变为按区块下载。

## 遮挡与半透明

场景由三维深度缓冲处理建筑、人物、树木和地面遮挡，不再使用二维建筑裁片排序。人物为朝向镜头的 16×32 透明像素平面，脚底对齐原地理落点；植被为固定朝南的直立透明平面，以圆润的顶点法线表达树冠柔和受光，透明区域通过 alpha test 剔除。角色名字使用同一像素字体，独立显示在头顶，不参与场景景深。

镜头至人物中心的射线遇到前方楼体时，将该整栋建筑降至 40% 不透明度；移开后恢复。植物遮挡同样按单株处理：将人物的非透明像素投影到附近植物平面，只有与植物非透明像素重叠且植物在人物前方时，才将该株平滑淡至 45%，移开后恢复；过渡约 180 毫秒。同原型的其他实例不随之淡出，保留 InstancedMesh 合并绘制和原有投影阴影。人物移动和地面通行仍使用现有一米材质格与建筑 footprint，不以装饰网格反推碰撞，也不开放建筑室内。

## 进入校园与身份认证

首页加载时若本标签页保存了账号令牌，先调用 auth-refresh 验证并续期以恢复菜单登录状态，不自动打开窗口或加载校园。未登录主按钮显示“登录”，不显示“账号”；注册、密码或统一认证登录成功后关闭登录窗口并停留首页，主按钮改为“进入校园”，同时显示“账号”。点击“进入校园”后验证当前会话，读取物品定义与角色；没有角色时在首页窗口完成名字、性别、捏脸与初始衣物选择，名字与性别按服务端 defaults 预填并可修改；角色准备成功才导航到 `/game/`。“账号”按钮提供独立的首页账号管理入口，显示角色用户名、注册邮箱及统一认证绑定状态，未绑定时提供绑定按钮，并可退出登录、清除本标签页会话；已有角色不会在管理入口登录后自动跳走。没有角色时也可以在创建表单中先绑定统一认证，再使用 preferred_username 与性别预填。

首页将已验证的 PocketBase 令牌、角色与物品定义保存在本标签页 `do-game-session` 启动快照中，`do-session` 保留登录令牌供下次首页进入使用。campus 不显示登录或创建表单、不执行 auth-refresh 或 OAuth；缺少准备好的启动快照时直接返回首页，并且不启动 Three.js。地图就绪时立即加载已准备的角色，背包直接使用同一快照，成功换装后更新快照以供刷新恢复。启动令牌过期、实时连接拒绝认证或背包接口返回 401 时，清除本地会话并回到首页。

启动快照格式版本为 2，增加角色性别；旧快照返回首页重新准备，不在游戏中推测补齐。启动快照只用于当前本地行走与持久化背包，不是服务端签发的联机票据，也不是授权依据。WebRTC 接入尚未实现：后续应在首页通过已验证账号申请短期游戏票据，campus 使用游戏票据建立连接；信令、准入和失效退出规则见[多人通信](networking.md)。

## 统一身份认证入口

首页账号窗口从 `users/auth-methods` 读取已启用的 OIDC 提供商，配置生效后显示“大工统一认证”按钮。调用 PocketBase 官方 SDK 的 `authWithOAuth2` 新标签页流程，使用内存 BaseAuthStore；成功后只将 PocketBase 用户令牌保存到本标签页的 `sessionStorage`，复用已有角色读取与创建流程，不额外使用 SDK 默认的 localStorage 会话。保留邮箱密码登录，用户名不能用于密码登录。SSO 登录已绑定身份时直接登录；未绑定时在首页账号弹窗中完成注册或绑定已有账号，使用同一次认证结果，不再次要求学校认证。绑定时将当前本地账号令牌装入同一个内存 BaseAuthStore 后调用 authWithOAuth2，保存返回的新 PocketBase 令牌并刷新账号绑定状态与角色默认值；不在游戏页面绑定或恢复登录。错误沿用首页账号窗口反馈。

统一认证在用户点击时同步打开普通 `_blank` 标签页，不指定弹窗尺寸、位置或浏览器工具栏特征；通过 SDK urlCallback 导航到授权地址，保留首页等待结果。授权标签页与首页断开 opener，仍沿用 PocketBase 的一次性回调订阅返回结果，结束后关闭授权标签页；登录和绑定共用同一打开方式。

首次 SSO 未绑定时，首页账号弹窗直接切换为注册引导，票据保存在本标签页 sessionStorage 的 do-sso-onboarding-ticket，不放入 URL；刷新后恢复弹窗并向后端检查有效期。服务端提供浏览器 Cookie 证明，页面不读取或自行构造学校身份。

首页弹窗默认显示“完成统一认证注册”，可以切换“已有账号”；按钮分别为“注册并绑定”和“登录并绑定”，不显示再次进行 SSO 的入口。邮箱注册要求验证码及确认密码，密码登录使用 PocketBase；拿到本地账号令牌后消费引导票据，关闭弹窗并显示“进入校园”。取消引导清除本标签页凭据；过期或其他浏览器打开时显示失效反馈，禁止提交。引导票据不替代登录令牌，创建角色和进入校园仍遵循首页准备流程。
