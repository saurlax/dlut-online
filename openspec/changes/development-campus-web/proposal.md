## Why

DLUT Online 是以整个大连理工大学为主题的第一人称 MMORPG。首批场景取材于开发区校区，产品名称和主界面以学校整体为主题。当前优先完成单人校园行走体验；俯瞰地图与地标搜索不符合目标。

## What Changes

- 保留官方轮廓生成的 27 个建筑及场地模型。
- 用第一人称角色替换轨道相机，支持鼠标环视、WASD 行走、Shift 奔跑与碰撞。
- 移除搜索、地标列表、浮动建筑标签、地图工具栏和 JS 桥接。
- 全部产品界面使用 Godot，保留必要按钮、准星、圆形小地图和校区选择面板，探索中不显示说明文本。
- Web 使用官方导出启动外壳；当前无活动、登录或多人联机。

## Capabilities

### New Capabilities

- `campus-model`: 官方轮廓驱动的首批场景写实风格模型。
- `web-campus-viewer`: 全 Godot 的第一人称校园探索体验。

### Modified Capabilities

无。

## Impact

Godot 客户端、角色物理碰撞、原生 UI 和 Web 导出配置；无需外部界面框架或游戏服务器。

本轮根据官方实景照片精修信息楼和图书馆外观。没有有效室内数据就不建模，不生成推测性房间或家具；来源记录留在 references/。项目约束由根目录 AGENTS.md 固化。

最新范围增加三校区：默认 lingshui，占位预留 panjin，eda 保留已有模型。左上原生圆形小地图和 M 键打开选择面板，通过场景切换传送；该要求替代此前只显示准星的限制。

首次启动增加原生封面，进入后暂停和传送不再弹出进入/继续按钮；官方 Web 加载页通过导出配置定制 DLUT Online 标识及进度条。

大地图按最新要求改为全屏，右上角竖向排列校区选择，删除关闭按钮，使用 M/Escape 收起。

大地图按最新要求改用固定默认比例尺、滚轮缩放与有边界的左键拖动，不再自动展示全图。

开发区资产统一归入 assets/campuses/eda/{data,models}，校区注册表声明数据路径，更新生成及导出流程；共享字体保留 assets/fonts。另两校区占位直接存于各自场景，不创建无依据的数据。GLB 与配套纹理保留为离线模型交换产物，游戏使用 TSCN。

仓库采用 apps/ 组织：现有 Godot 项目整体移入 apps/client/，同步工具、忽略规则和编辑器入口说明；本次不新增服务端或首页功能。

资源托管改由 apps/server 的 Go/Chi 服务提供 /web/，删除 Python 预览脚本；首页及多人后端不在本轮范围。

新增每次 push 的多平台构建：Go 支持 PORT（默认 8060），镜像内置 Godot Web，另提供 Windows x86_64 与 macOS universal 客户端 ZIP。

本轮补充空格跳跃与 Web 加载资源的 MB 计数和百分比。

本轮为桌面客户端增加 DO_ENV / DO_SERVER_URL 配置读取和原生导出注入，不实现网络请求。
