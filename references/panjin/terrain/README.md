# 盘锦校区地形资料

已归档Copernicus GLO-30 2021版N40E122瓦片的73×70原始Float32样本，取得日期2026-09-17。水平基准WGS84，垂直基准EGM2008，单位米；来源、裁剪窗口及校验摘要见[source.json](source.json)。主采集期2011–2015，局部补洞可能更早，未取得逐像元质量信息或校内高程控制点。

这是含建筑和植被的DSM，不是裸地测量。场景以共享WGS84原点直接采样，经3×3最小值、3×3均值及建筑基面估计生成10米预览网格；10米网格不增加源数据约1角秒的精度。建筑、道路及两端碰撞共同更新，不能据此确认入口、台阶或小平台标高。处理与许可见[共享地形依据](../../shared/terrain/basis.md)。

OSM与历史官网平面档案见[mapping/](../mapping/)；旧DLUTMap三维bound不参与生成。后续测绘资料须记录采集日期、水平和垂直基准、精度与许可，未知项明确标注。

C09基础教学部西侧停车地面以OSM way/1263777289 v1及影像核对恢复，共用地形三角面，2厘米抬升仅用于渲染和通行，不代表路沿高度。小地图、大地图和两端碰撞读取同一地面范围；其余三块停车区域保留待核对，详见[地面来源记录](../mapping/ground-surfaces.json)。
